## 优化判断

优先继续拆解scorer数据准备，其次评估refiner网络/TensorRT。
网络合计约2.728 s（37.1%）：假设其他阶段不变，即使网络耗时降至零，仍约4.63 s；
网络独立加速2倍时整体约5.99 s。因此仅转换两个网络无法据此承诺1秒注册。
渲染只占约2.5%，当前不支持优先投入渲染kernel优化。
减少候选可能同时影响裁剪、网络等阶段，但需另行评估输出和失败率。
