# room0804 local evidence assets

These files were copied read-only from the S1 map directory
`/var/maps/room0804` for offline analysis. They are historical evidence, not
proof of the robot's current map or localization state.

The large `global_cloud_cleaned.pcd` and `global_cloud_cleaned.esdf` files stay
on the local workstation and are ignored by Git. Only this inventory and
`ASSET_MANIFEST.sha256` are versioned for those two files.

| Artifact | Bytes | SHA-256 | Git policy |
| --- | ---: | --- | --- |
| `global_cloud_cleaned.pcd` | 174,182,256 | `08d273b30c21f7ee4d9b4c917ac95106ae268d45bed91a299e99198b61ffd5eb` | local only |
| `global_cloud_cleaned.esdf` | 82,985,879 | `4619524463bf94c4c5f3cb823a958813498f95710fb03b3a3f13ba50e8936c96` | local only |

The small `map.yaml`, `map.pgm`, `poses.txt`, and `times.txt` inputs are kept in
Git because they are useful for reproducing 2D-map and trajectory checks and do
not create the large-binary repository problem.

To verify the two local-only assets, run `sha256sum -c ASSET_MANIFEST.sha256`
from this directory. A missing-file result means the local evidence must be
restored from an authorized source before replay; it must not be silently
replaced by a file with the same name.
