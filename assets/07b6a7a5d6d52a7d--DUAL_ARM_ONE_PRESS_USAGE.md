# 双臂单次确认直接正式跟随

独立入口 `run_dual_arm_one_press.sh`，共用已验证的双臂控制循环。
原 `run_dual_arm_direct.sh` 保留两次确认模式。

只读检查：

```bash
bash teleoperation/run_dual_arm_one_press.sh --seconds 60
```

现场执行：

```bash
bash teleoperation/run_dual_arm_one_press.sh --execute --seconds 600 \
  --speed-rad-s 1.0 --gripper-speed-m-s 0.16
```

本入口没有 `--align-speed-rad-s` 参数，也没有自动慢速对齐阶段。

## 每侧操作

1. 手动调整该侧GP主臂，使七关节映射目标与G1实测的差值绝对值全部严格小于15°；15°整不通过。
2. 主从均在该侧保守限位内、反馈/控制器正常、该臂静止0.5秒后显示READY。
3. 按本侧固定键一次，直接进入FOLLOWING，默认速度上限1.0rad/s。
4. 再按本侧固定键，仅暂停该侧手臂并尝试保持该侧夹爪；重新启动仍需满足READY并重新按键。

左右独立，可以仅启动一侧，另一侧保持LOCKED。
未就绪时的点击不会保存；就绪后有效点击碰到重复反馈时，最多等待点击后300ms的新反馈。
等待期间条件失效或点击过期，不会自动启动。
固定键需松开至少30ms才能再次识别按压。

正式跟随直接采用正常速度上限，但第一个轨迹段从从臂实测位置开始；保留每100ms段的速度限幅，不瞬间跳过起步误差。
与原模式相比，允许开始正式跟随时存在接近15°的误差（原模式提速前要求<3°），请预留追赶目标的活动空间。
运行中主臂越界限幅并继续跟随；启动前原始目标越界仍不能READY。
瞬时速度1.2倍、逐关节持续速度1.1倍达150ms、15°轨迹偏差、反馈新鲜度、实际越界等保护保留。

## 保留功能及记录

- 左右夹爪各自由对应扳机控制，本侧FOLLOWING后先松开扳机解锁。默认160mm/s。
- 左右任一STOP=-1均触发全局急停，停止双臂轨迹/请求底盘停止并尝试保持双夹爪。
- 600秒上限，执行模式从任意一侧首次FOLLOWING开始计时；只读从进入循环开始计时。
- 默认+104ms时钟补偿，可由 `--g1-clock-offset-ms` 覆盖。
- 日志使用 `lerobot_runs/dual_arm_one_press_日期_时间_PID` 前缀，包含事件、高频samples、metadata和recording_status四个文件。
- 元数据和start事件标记one_press=true，便于与原两次确认记录区分。

仍无双臂互碰和环境避障检查；单侧暂停/夹爪保持只代表发出保持目标，不能等同物理急停。新模式仅完成离线验证，未启动真机。

2026-09-22：按用户要求将单次确认入口双夹爪默认速度设为0.16m/s（160mm/s），速度参数校验上限与SDK声明的0.2m/s一致。此为SDK命令速度，实际速度和更高速下的停止效果尚待真机验证。
