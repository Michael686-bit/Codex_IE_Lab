# G1 双臂 RViz 仿真

这个包提供第一版离线运动学可视化：腰部/升降机构 5 个关节和左右臂各 7 个关节由滑块控制，`robot_state_publisher` 发布 TF，RViz2 显示机器人和两个末端坐标轴。仿真只发布 ROS 话题，不连接 Galbot SDK，也不发送真机运动命令。

## 1. 构建

```bash
cd "/home/lsy03/文档/ChatGPT/VLA G1 项目"
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select g1_rviz_sim
source install/setup.bash
```

## 2. 先用内置模型验证链路

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch g1_rviz_sim display.launch.py
```

此模式使用包内的可移植几何模型，确保即使没有厂商网格，也能先验证 19 个关节、TF 和 RViz 配置。

## 3. 使用本机的银河 G1 网格模型

当前机器已有 SynthNova 资源包中的真实 `galbot_one_golf.urdf`。启动时把它传给 launch：

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch g1_rviz_sim display.launch.py \
  urdf_path:=/home/lsy03/Lsy03_document/仿真软件/extracted/synthnova_delivery_20260801/delivery_dir/synthnova_delivery/sythnova_assets/robots/galbot_one_golf/urdf/galbot_one_golf.urdf
```

也可以先设置环境变量，之后省略参数：

```bash
export G1_URDF_PATH=/home/lsy03/Lsy03_document/仿真软件/extracted/synthnova_delivery_20260801/delivery_dir/synthnova_delivery/sythnova_assets/robots/galbot_one_golf/urdf/galbot_one_golf.urdf
ros2 launch g1_rviz_sim display.launch.py
```

启动器会把 G1 的网格引用解析为本地 `file://` URI，把头部和夹爪关节固定在 URDF 零位，并保留真实模型中的 `leg_joint1~5` 和双臂 14 个关节，因此会生成 19 个滑块。当前供应商 URDF 中的 `torso_joint` 是固定连接；这里的腰部控制对应其实际下方的五关节升降机构。

## 4. 可观察的话题

```bash
ros2 topic echo /joint_states
ros2 topic echo /g1/left_ee_pose
ros2 topic echo /g1/right_ee_pose
ros2 run tf2_tools view_frames
```

RViz 中的两个末端坐标轴分别对应：

- `left_arm_end_effector_mount_link`
- `right_arm_end_effector_mount_link`

ROS 关节角使用弧度；滑块的上下限来自 G1 双臂关节的 URDF 限位。第一版的 RViz RobotModel 使用 visual geometry，碰撞检测和动力学仿真留到后续 MoveIt/Gazebo 阶段。
