# R03：原始深度 / LingBot 深度对比

## 结果与边界

SAM3、LingBot各调用一次；FDP两次均HTTP200。V5两组均拒绝，候选只作诊断。没有SDK或运动调用。

固定同一帧RGB、K/D、TF、mesh和LingBot ROI6 mask，仅切换深度。默认ROI0是相邻空箱，已依据用户指定的装板箱及叠加图绑定ROI6。该mask包括板面及外扩区域，触及图像边界；结果不等于最优mask性能。

标定板参考是模型安装假设下的名义参考，不是独立真值：mesh中心截面的内壁代替A角实际接触面，用户给定零间隙、两侧10mm白边及2mm厚度；图案轴映射从用户红蓝标注照片的ID单应性确定。原始mesh底面射线高度约-172.497mm，承托面实物匹配仍未验证。未使用V5/FDP输出反推安装关系。

## 解释

本帧无法得出LingBot提高绝对准确度的结论。FDP两深度中心相差7.50mm；名义参考下raw中心更近，LingBot方向更近。V5两组均无正式接受位姿。单帧无重复性统计，不能外推整体性能。
