## 实现

- `release_final/`：实际S1运行的不可变源码与参数快照。
- `icp6d.py`：NumPy/SciPy/OpenCV CPU实现；静态对象KD树、法向对应、IRLS、解析增量。
- `run_batch.py`：只推理与计时，无标签输入。`evaluate.py`：独立读板参考评分。
- `inputs_manifest_v2.json`：64输入条件及原始哈希，15套D/H raw以RGB/K/TF哈希精确匹配后补齐，全部分支使用同一确认mask。
- `orin_final/`：全部384次实际输出、镜像、inspect、源码哈希、日志。
- `snapshots/`、`local_*`、`orin_fast/`：失败/消融过程证据，不覆盖旧结果。
- `depth_consistency.json`：板面预测深度与RGB-D的离线一致性诊断，未被推理读取。

计时包括深度滤波、点云、法向、下采样、初值、ICP、质量判定和必要重试。静态模型加载与文件/容器初始化另记，不缓存帧点云/初值；固定最多迭代和0.90秒检查预算。所有实测≤1秒并非对任意未来系统调度的硬实时证明。

初始选择假设开口可见且大致朝上（约30°以内），输出roll/pitch自由优化；任意倒置箱体未验证。底面因既有mesh几何差异从拟合剔除，保留顶沿和侧壁。原OBJ文件未修改；“172mm模型”仅作为独立失败消融，最终仍使用原175mm几何。

## 复现

先设四个数学库线程变量为1，再运行：

```bash
python3 run_batch.py \
  --manifest inputs_manifest_v2.json --input-root inputs/cases \
  --model source_model.obj --config config_final.json \
  --output NEW_OUTPUT_DIRECTORY --repeats 5
python3 evaluate.py NEW_OUTPUT_DIRECTORY
```
