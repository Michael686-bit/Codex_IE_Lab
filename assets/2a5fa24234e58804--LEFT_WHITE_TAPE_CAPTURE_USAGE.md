# 左臂白色胶带入箱采集

沿用左臂牛奶采集的遥操、预热、记录键分段和left7记录器；任务改为将桌面上的白色胶带放入蓝色料箱。默认目标40条，会话上限3600秒。

2026-10-09按本次继续采集要求改为新增40条；今天已完成的两条属于另一个会话，不计入这个入口的新会话计数。左臂、七路记录、夹爪60mm/s和原有保护参数沿用试采配置。

## 启动

```bash
cd "/home/lsy03/文档/ChatGPT/VLA G1 项目"
bash teleoperation/run_capture_left_white_tape.sh --execute
```

仅检查配置，不连接机器人、手柄，不启动测时或遥操：

```bash
bash teleoperation/run_capture_left_white_tape.sh --execute --dry-run
```

目标数量和时长可以调整，例如先录5条：

```bash
bash teleoperation/run_capture_left_white_tape.sh --execute --target-episodes 5 --seconds 600
```

3600秒是整个会话的时限，包含复位、等待落盘等时间，不保证能录完40条。重新启动创建新会话，计数从0开始；例如本轮已经完成5条，下一次可设置`--target-episodes 35`，最终按各批审计合计。仍可传`--target-episodes 50`调整目标。

## 固定配置

- 仅左臂和左夹爪遥操，固定`--active-arm left`。
- 左夹爪SDK指令速度固定0.06m/s（60mm/s）；不是实测物理速度。
- 关节速度上限默认1.0rad/s，沿用原入口的范围校验，可用`--speed-rad-s`降低。
- 固定`left7`：头左RGB、左腕RGB、左腕深度、右前环视RGB、左臂关节、左夹爪、左腕力。
- 每条任务文本固定为：`Pick up the white tape from the table and place it into the blue bin.`

任务、手臂、传感器配置和夹爪指令速度通过末尾参数固定；其他物体或其他放置终点应使用对应任务入口，避免指令与示教不一致。

## 每条操作

1. 等待启动预热，对齐左侧主从臂，按左固定键开启跟随。
2. 按记录键开始，抓起白色胶带，放入蓝色料箱，松爪并撤手，再按记录键结束。
3. 抓错、掉落或未完成按取消键；失败原件保留，不计入完成目标。
4. 等待落盘完成，再按左固定键暂停左臂，然后人工复位。结束录制不会自动暂停左臂。
5. 达到目标只提示，遥操仍继续；完成后暂停左臂，再Ctrl+C退出。

记录键：左索引1或右索引10；取消键：左8或右17，与现有入口相同。完成计数表示操作者正常结束且原件落盘完成，仍需后续画面、动作和时序质量检查。

## 40条的摆放建议

准备5种桌面布局，每种采8条，适当改变白色胶带位置与朝向。牛奶、方块等可同时出现在场景中并交换位置，避免胶带始终占据固定位置；初期保证物体可见、易抓，固定蓝色料箱位置。每条只抓白色胶带。

这40条仅补充白色胶带指令。后续需在相同或相似布局下采集牛奶、方块等目标的对应指令，才能形成按语言选择目标的数据覆盖；本脚本不会自动切换任务。
