# S1 RViz2 主诊断实现（离线/被动实时）

日期：2026-08-22

## 主实现决策

自 2026-08-31 起，本目录中的
`ros2_ws/src/s1_rviz_demo` 是项目唯一继续演进的导航/ESDF RViz 主实现。
它统一承载：

- S1 URDF 与离线关节显示；
- 2026-08-27 历史 1 m 预检查失败回放；
- 厂家真实 `EsdfGrid` 捕获帧、距离切片与碰撞球投影回放。
- 厂家真实 `TsdfGrid` 调试表面点的离线回放与可选 1 Hz 被动桥接；
- 三路 S1 原始 LiDAR 和实时 TF 的被动 SSH 桥接；
- `room0804` 二维占据地图与三维全局 PCD 的本机叠加显示。

外部学习仓库
`/home/lsy03/Lsy03_document/galbot_s1_SDK_learning/navigation/ros2_ws/src/s1_room0804_rviz`
只作为静态 `room0804` 地图/点云和历史场景参考，不再增加新诊断功能。
这样可以保留其历史证据价值，同时避免两套 viewer 继续分叉。

## 目的

使用本机官方 S1 URDF 和视觉 mesh，在 ROS 2 Humble / RViz2 中离线显示
完整机器人，并通过 `joint_state_publisher_gui` 调整关节。

本实现也可以离线回放已经授权捕获并在本地保存的 PNS/Motion `EsdfGrid`；
回放不会连接 S1，且不能等同于实时 PNS 碰撞计算。
`view_live_lidars.launch.py` 则通过用户已建立的 SSH ControlMaster
启动被动传感器 reader，它不导入 Galbot SDK，也不发布 S1 DDS 话题。

## 安全边界

- 离线 launch 不连接 S1；实时 LiDAR launch 仅使用已授权 SSH 被动读取；
- 不初始化 Galbot SDK；
- 不发布任何真机控制指令；
- 不修改 S1 当前地图、定位状态或融合/PNS 配置；
- 滑块值只改变 RViz2 中的几何模型；
- URDF 零位不是安全姿态或真机恢复目标。


回放厂家真实 ESDF 捕获帧：

```bash

```

回放 2026-09-02 同步捕获的厂家 TSDF 调试点帧：

```bash
ros2 launch s1_rviz_demo view_captured_tsdf.launch.py
```

该离线 launch 发布 `/s1/tsdf/surface`、`/s1/tsdf/slice` 与
`/s1/tsdf/diagnostic_markers`，并在 `map` 坐标系中叠加 room0804 地图。
完整证据与参数见
`experiments/20260902_s1_tsdf_rviz/README.md`。

回放 2026-08-27 历史预检查失败：

```bash
ros2 launch s1_rviz_demo replay_1m_failure.launch.py
```

实时三路 LiDAR、S1 模型、`room0804` 二维地图与三维全局 PCD：

```bash
export ROS_DOMAIN_ID=84
export ROS_LOCALHOST_ONLY=1
ros2 launch s1_rviz_demo view_live_lidars.launch.py
```

经明确授权并上传 `/tmp/s1_tsdf_stream_20260902.py` 后，可短时开启 1 Hz TSDF：

```bash
ros2 launch s1_rviz_demo view_live_lidars.launch.py publish_live_tsdf:=true
```

此参数默认 `false`。实测厂家 Python/embosa 大消息 reader 约占一个 CPU 核的
59--64% 和 410--450 MB RSS，因此只能用于短时受监督诊断，不应常驻。

该 launch 默认发布：

- `/map`：`nav_msgs/OccupancyGrid`，reliable + transient-local；
- `/s1/map/global_cloud`：每 10 个源点取 1 个的
  `sensor_msgs/PointCloud2`，reliable + transient-local；
- 三路 `/s1/lidar/*_raw`、实时 TF 和携箱 Marker。

地图默认读取：

```text
/home/lsy03/文档/ChatGPT/S1/experiments/20260827_s1_navigation/s1_room0804/map.yaml
/home/lsy03/文档/ChatGPT/S1/experiments/20260827_s1_navigation/s1_room0804/global_cloud_cleaned.pcd
```

可用 launch 参数分别关闭或调整：

```bash
ros2 launch s1_rviz_demo view_live_lidars.launch.py \
  publish_2d_map:=true \
  publish_3d_map:=true \
  map_point_stride:=10
```

PCD 不被复制到 ROS 包或 Git；发布器使用内存映射读取二进制 PCD，
丢弃非有限 XYZ，并在资产缺失或格式不匹配时明确报错。

`ROS_LOCALHOST_ONLY=1` 将 ROS 2 发现和通信限制在本机，避免在实验室网络上
发现或被其他 ROS 2 设备发现。

默认使用 `color_mode:=clear`：左臂为蓝色、右臂为橙色、机身为浅灰色、
立柱/轮组/夹爪为深灰色，便于观察关节和左右臂。RViz2 对官方 GLB 的内嵌
PBR 纹理支持不完整，`original` 模式可能出现机身整体偏黑。

要查看 GLB 原始材质：

```bash
ros2 launch s1_rviz_demo view_s1.launch.py color_mode:=original
```

可覆盖默认 URDF：

```bash
ros2 launch s1_rviz_demo view_s1.launch.py urdf_path:=/absolute/path/to/model.urdf
```

## 预期结果

- RViz2 的 Fixed Frame 为 `base_link`；
- RobotModel 显示 S1 完整视觉模型；
- Joint State Publisher 窗口列出可动关节；
- 拖动滑块只更新 `/joint_states` 和 TF，从而改变 RViz2 模型姿态。

## 版本化边界

Git 只保存 `ros2_ws/src/`、说明文档、配置和小型证据摘要。colcon 生成的
`build/`、`install/`、`log/`，以及原始 `.pb`/`.npz` ESDF 帧均由根目录
`.gitignore` 排除；二进制证据由相邻 `ASSET_MANIFEST.sha256` 固定哈希。
