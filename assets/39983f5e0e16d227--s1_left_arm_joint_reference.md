## 零点的含义

对每个旋转关节，`q=0` 是 URDF/编码器标定采用的几何参考角。它只定义
父、子连杆在零角时的相对变换。它不是 factory home、自然姿态、安全姿态、
停放姿态或恢复目标。禁止仅因为一个向量全为零就将其发送到真实机器人。

关节正方向遵循相应关节坐标系中 `+Z` 轴的右手定则。所有七个关节在各自
局部关节坐标系内都写为 `axis="0 0 1"`，但这些局部坐标系方向不同，并会被
上游关节转动。因此某个下游关节在机器人基座坐标系中的实际旋转轴随当前
姿态变化。

## 功能直觉（推断，不是官方语义名称）

官方模型只把关节命名为 joint1 至 joint7。根据串联结构、共同关节位置和
0.49 m/0.43 m 两段主要连杆，可以用以下方式建立直觉：

| 关节 | 大致作用 | 运动影响范围 |
|---|---|---|
| joint1 | 肩部第一旋转轴 | 整条手臂 |
| joint2 | 肩部第二、近似正交旋转轴 | 整条手臂 |
| joint3 | 上臂/肘部姿态调节轴 | 肘后全部连杆 |
| joint4 | 主要肘部弯曲轴 | 前臂及手腕 |
| joint5 | 前臂/腕部姿态调节轴 | 手腕和工具 |
| joint6 | 手腕弯曲轴，范围最窄 | 末端工具 |
| joint7 | 最末端工具姿态旋转轴 | 末端工具 |

这些简称只用于学习直觉。具体“向前、向外、抬起、下压”的视觉方向取决于
当前全部上游关节角，必须通过模型可视化或低风险、逐步确认的实机观察验证。
