# S1 左臂关节状态只读实验

日期：2026-08-20
安全等级：L2 实时只读
执行位置：S1 `galbot-echo`，`/home/galbot/Lsy03`
运行环境：`/home/galbot/ie_lab/bin/s1-python`

## 目标

通过 Galbot SDK 初始化并读取 `left_arm` 的关节名称、位置和
`JointState` 字段。不发送任何运动命令。

## 安全边界

- 预期运动：无；
- 涉及设备：仅左臂状态读取；
- 未涉及：右臂、夹爪、躯干、底盘；
- 未调用：`set_*`、`execute_*`、规划或轨迹接口；
- 运行结束后正常释放 SDK 资源。

## 结果

- SDK 初始化和资源释放成功；
- 返回 7 个左臂关节：`left_arm_joint1` 至 `left_arm_joint7`；
- 位置快照（rad）：
  `[0.778807, -1.784247, -0.236796, -1.689812, -0.229330, -0.277627, -0.748966]`；
- 速度均为零或约 `1.8e-4 rad/s` 以内，采样时左臂基本静止；
- 七个关节的 `effort` 均返回 `0.0`；
- `current` 返回带符号的小数，范围约 `-0.113` 到 `0.032`；
- SDK 输出 1.9.1 可用提示。此提示本身不能替代已安装版本和机器人
  GBS 版本的显式检查。

## 解释边界

- 本地 SDK 类型存根把 `JointCommand.effort` 说明为关节扭矩 N·m，
  但没有给 `JointState.effort` 或 `JointState.current` 标注单位和 S1
  驱动映射语义；
- 全部 `effort=0.0` 不足以证明机械关节实际承受零扭矩，更可能是该
  状态字段在当前硬件/驱动路径未填充、未估算或使用默认值，仍待验证；
- `current` 的正负号应先视为驱动定义的方向符号。不能在缺少型号匹配
  文档或标定前把数值直接解释为力、扭矩或故障；
- 这组位置只是一时刻实测快照，不是 home、初始、安全或恢复目标。
