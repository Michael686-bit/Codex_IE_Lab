# 04 Teleoperation

该目录现在包含两个机器人版本：

- `g1/`：`galbot_one_golf` 遥操；
- `s1/`：`galbot_s1` 遥操，使用独立场景和
  `synthetic_data/04_gp001_s1_remote_control` 输出目录。

这个 demo 展示如何把 GP001 遥操设备通过 Remote Control Lite 映射到
Physics Simulator 中的 `galbot_one_golf`。它只包含机器人控制所需功能：

- GP001 左、右 7-DoF 机械臂分别控制机器人左、右 7-DoF 机械臂；
- 右摇杆控制全向底盘前后、横移和旋转；
- 左摇杆前后直接控制腿部升降，使机器人站起或蹲下；
- 左手 LT、右手 RT 分别控制左、右夹爪，按下闭合、松开张开；
- 左、右夹爪按钮分别控制机器人左、右夹爪；
- 场景挂载头部、左手腕和右手腕三个 RGB 相机；
- 运行时以 20 FPS 弹出头部、左手腕和右手腕三个 OpenCV 实时窗口；
- 从程序启动开始自动记录 Physics Snapshots，退出时保存到
  `synthetic_data/04_gp001_remote_control/snapshot/physics_snapshots.h5`；
- 急停按钮会立即停止底盘并暂停关节指令。

这个 demo 使用独立场景
`scene/04_teleoperation/gp001_teleoperation_scene.json`。场景包含机器人、桌子、
桌面上的可乐资产和一个箱子，不包含基础 cube/cylinder，便于直接进行遥操抓取。

## 运行

直接运行 `python 01_gp001_remote_control.py`。在新的宿主机首次运行且串口权限
不足时，Python 会自动安装串口规则，只需按终端提示输入 sudo 密码；不需要手工
配置或注销登录。之后重新插拔设备会继续自动生效。

场景 JSON 已随示例提供；只有修改场景内容后才需要重新生成：

```bash
python 00_generate_scene.py
```

然后连接 GP001，在 `encryptionManager` 环境执行：

```bash
python 01_gp001_remote_control.py
```

程序默认通过 `/dev/serial/by-id` 自动识别 GP001。也可以手动指定：

```bash
python 01_gp001_remote_control.py --port /dev/ttyACM0
```

### Docker

udev 规则必须安装在宿主机，不能由容器内的 Python 脚本替代。启动容器时传入
设备和宿主机设备组：

```bash
docker run \
  --device=/dev/galbotV1RemoteOperate:/dev/galbotV1RemoteOperate \
  --group-add "$(stat -c '%g' /dev/galbotV1RemoteOperate)" \
  <其他参数> <镜像>
```

进入容器后仍直接运行 `python 01_gp001_remote_control.py`，脚本会自动发现稳定
设备名或 `/dev/serial/by-id`。

按 `Ctrl+C` 退出。Physics Simulator 开启实时同步；遥控器暂时没有新数据时，
仿真仍会逐步推进，不会阻塞桌面物体的正常下落。该示例直接读取 Remote
Control Lite 的合并帧，不依赖 ROS，也不包含相机发布、任务级抓取辅助等
非必要功能。

## Snapshot、渲染回放和视频

`01_gp001_remote_control.py` 从启动开始以约 30 Hz 自动记录 Physics
Snapshots；按 `Ctrl+C` 或 `q` 退出时写入 HDF5。之后顺序执行：

```bash
python 02_render_snapshots.py
python 03_images_to_video.py
```

默认输出结构：

```text
synthetic_data/04_gp001_remote_control/
├── snapshot/physics_snapshots.h5
├── head_camera/
├── left_wrist_camera/
├── right_wrist_camera/
├── head_camera.mp4
├── left_wrist_camera.mp4
└── right_wrist_camera.mp4
```

渲染回放默认按照录制的仿真时间播放。使用
`python 02_render_snapshots.py --no-realtime` 可以尽快渲染，使用 `--headless`
可以不显示 Isaac Sim viewport 和 OpenCV 窗口。
