## 实现内容与证据

1. `fast_xyz.py`：消除scorer中“160×160 → 1280×720 → XYZ → 160×160”的全尺寸中间结果，
   直接求最终采样点，保留两次nearest取整、align_corners=False和边界补零。
   真实帧19,353,600个归一化XYZ元素逐元素一致；3种尺寸×5种变换（含边界、零深度）测试也逐元素一致。
2. `net_opt.py`：卷积channels-last、30组Conv/BN推理融合、卷积/线性权重预先FP16转换、
   独立特征计算微批次64；不删除候选、不减迭代、不修改磁盘权重。
   此组会带来数值及最佳候选变化，因此最终位姿不是原版逐元素等价；差异如表。
3. `quiet_inference.py`：只对新函数副本删去logging.info/debug表达式，避免禁用日志时仍求值
   GPU tensor f-string而同步。AST不删除赋值、分支、返回或算法数学操作。源文件只复制到新镜像层，原件不改。
4. `infer.py`：独立常驻模型的文件输入入口，逐次计时和保存位姿。默认`--mode exact`只开采样优化；
   本次验收用`--mode fast --threads 1 --batch-size 64 --quiet-functions`。

CuDNN注意：原register的set_seed会关闭benchmark；最初仅外层设置的“fast_cudnn”组没有
持续启用benchmark。后续tune_deterministic在set_seed后恢复benchmark并保留deterministic，
不能把最初那组收益归因于cuDNN调优。去除attention权重输出的单独测试收益很小，最终未采用。
