# Orin 单帧 FDP 隔离测速 — 2026-09-18

本实验只验证一帧离线 FDP++ 在 S1 Orin 上的可运行性和耗时，不做整体验证、精度验收或机器人控制。

## 输入与隔离

- 输入：`experiments/20260903_fdp_baseline/cases/right_wrist_20260907_01_lingbot_operator1/input`
- RGB、LingBot 深度、mask、K、mesh 共六个输入文件；运行前后 SHA-256 未变化。
- 新镜像：`codex/fdp-orin-probe:20260918`，从既有 `dual_arm_robot:dev` 派生。
- 容器：`--network=none`、根文件系统只读、输入只读、6 CPU、8 GiB、NVIDIA runtime。
- 未调用 Galbot SDK、相机、远端感知/FDP HTTP 服务或任何运动接口。

Dockerfile 和计时包装器只存在于本实验目录；FDP 源码和模型权重均从基础镜像只读使用。

## 结果

| 路径 | 模型初始化 | 首帧 `first_frame_track` | 进程总墙钟 |
|---|---:|---:|---:|
| 纯 FDP，Cutie tracker 关闭 | 106.932 s | **11.291 s** | 128.646 s |
| 当前默认路径，Cutie tracker 开启 | 54.444 s | **12.978 s** | 78.354 s |

纯 FDP 首帧和默认路径均返回有限 4×4 位姿；两条路径返回矩阵一致。默认路径额外约 1.7 s。
模型初始化包含 checkpoint 加载、CUDA/nvdiffrast 初始化等一次性成本；第一次运行还包含
nvdiffrast JIT 编译，因此不能把总墙钟当作每帧耗时。

## 结论边界

在当前未做 TensorRT/FP16 专项优化、使用 252 个初始候选、`est_refine_iter=2` 的实现下，
Orin 稳态单帧 FDP 约 **11–13 秒**。这远高于远端 RTX 4090 服务此前约 0.5–1.2 秒的服务/客户端计时，
当前不能认为满足 1 秒级需求。

本实验只证明“能在 Orin GPU 上跑通并返回位姿”，不证明绝对精度、抓取精度或跨帧稳定性。
