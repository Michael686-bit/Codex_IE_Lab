# 重要决策记录（DECISIONS）

> 只记录重要的项目级决策。每条包含：日期、决策、理由、备选、状态。

## Decision 001 — 知识库采用 Git-tracked Markdown

- 日期：2026-08-15
- Decision：项目长期知识以 Git 跟踪的 Markdown 文件为 source of truth
- Reason：跨 Session / 跨模型 / 跨工具可恢复；可 diff、可回滚
- Alternatives：SQLite / 数据库；专用知识管理 App；依赖单个 Session 记忆
- Status：Accepted

## Decision 002 — OpenCode Session 不是长期知识唯一来源

- 日期：2026-08-15
- Decision：OpenCode 负责 Session / Agent / Tool / 上下文；持久项目事实沉淀到 docs/
- Reason：Session 可能丢失、不可移植；OpenCode 已提供 Session 管理，不重复开发
- Alternatives：自建会话数据库 / 对话地图 Web App
- Status：Accepted

## Decision 003 — third_party 默认只读

- 日期：2026-08-15
- Decision：`third_party/` 只放参考原始代码，默认不直接修改；需改时复制到 learning / experiments 或建立 fork/patch
- Reason：保持官方 / 交大 / 第三方 / 自研代码可区分，避免污染参考实现
- Alternatives：直接在 third_party 内改并打 patch 管理
- Status：Accepted

## Decision 004 — 未验证信息标注 NEEDS_CONFIRMATION

- 日期：2026-08-15
- Decision：所有知识标注可信度（VERIFIED / NEEDS_CONFIRMATION / OBSERVATION / HYPOTHESIS / HISTORICAL），未验证不得写 VERIFIED
- Reason：防止 AI 推测混入项目事实
- Alternatives：不标注、依赖个人记忆
- Status：Accepted

## Decision 005 — 小步实验与可复现验证

- 日期：2026-08-15
- Decision：优先状态读取 → 仿真 → dry-run → 小幅运动 → 完整运动，避免直接运行大型完整系统
- Reason：真机安全 + 问题定位效率
- Alternatives：直接跑完整 Demo 后逆向理解
- Status：Accepted

## Decision 006 — 上下文按需加载

- 日期：2026-08-15
- Decision：opencode.json 的 instructions 只自动加载 PROJECT_CONTEXT + CURRENT_STATE；其余 docs 按需读取
- Reason：避免 token 浪费；保持 Agent 启动轻量
- Alternatives：自动加载整个 docs/
- Status：Accepted
