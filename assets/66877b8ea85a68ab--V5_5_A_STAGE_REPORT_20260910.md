# V5-5 A 阶段报告：倾斜证据与验证工具修复

日期：2026-09-10。状态：**A 阶段完成；B 阶段 V5-5 主算法未开始。**

## 本阶段目的

修复倾斜证据工具的可追溯性问题，确认图像投影和数值结果来自同一支持集，
补充倾斜估计器在正常、缺失、噪声、退化和竞争平面条件下的停止行为。所有
工作均为本地离线处理；没有连接机器人、调用 SAM3/LingBot/FDP 或修改 V5-5
位姿算法。

## 具体改动

1. `validate_tilt_h01l_h03l.py` 更新为 v2：记录体素化输入的行优先首像素
   顺序、每个候选的 RANSAC/TLS 参数和种子、原点、单位法向、前后支持集合、
   支持点坐标及对应像素；将原始 SVD 奇异值与按点数归一的 PCA 标准差分开，
   退化窄条带/单线不再被空间尺度误判为充分平面。
2. `render_tilt_h01l_h03l.py` 更新为 v2：直接读取保存的 post-TLS 支持像素
   和点坐标，渲染时不重新拟合；raw 与 LingBot 强制使用同一确认 mask，并用
   当前像素、K、TF 重建支持点，要求最大绝对误差不超过 `1e-6 m`。
3. `validate_tilt_synthetic.py` 更新为 v2：加入正负 X/Y 单轴、组合倾斜、
   随机缺失、连续遮挡、XYZ 噪声、窄条带、单线和两个竞争平面。
4. 新增 `tests/test_tilt_validation.py`，覆盖支持集/像素映射、前后拟合记录、
   归一化平面尺度、退化拒绝、竞争平面保留和渲染不重拟合。

## 验收结果

- 真实 H01L/H02L/H03L v2 倾斜验证完成。每帧 raw/LingBot 均产生 9 个高度
  分位候选；代表平面支持点均保存并可追溯。
- 最新投影接触表的六组图全部使用确认 mask；mask 哈希按帧在 raw/LingBot
  之间一致；保存支持点由像素/K/TF 重建的最大绝对误差均为 `0.0 m`。
- 真实观测的倾斜中位数仍为：LingBot 5.51°/5.95°/4.92°，raw
  5.59°/7.17°/5.59°；FDP 参考为 7.50°/8.61°/7.28°。该结果支持非零倾斜
  证据，但不把任一来源当作真实角度。
- 合成 7 个常规场景、2 个退化场景和 1 个竞争平面场景全部通过固定门限：
  常规场景法向误差不超过 1°，窄条带/单线被拒绝，竞争平面保留为歧义。
- `OPENBLAS_NUM_THREADS=1 python3 -B -m unittest discover -s experiments/20260907_bin_rim_pose/tests -q`：62 项通过。
- `python3 -B -m unittest discover -s experiments/20260903_fdp_baseline/tests -q`：21 项通过。
- 新增脚本均通过 `py_compile`；A 阶段输出资产清单哈希复核通过。

## 证据边界

点云平面仍是“近水平顶部候选”，可能混入内壁、法兰、筋条或 mask 区域；
支持点落在目标图像区域不等于平面身份已经证明。FDP 高度轴与观测法向接近
只说明方向一致，不能作为独立真值。合成点云是数学平面测试，不是 mesh 渲染、
真实深度噪声或完整机器人遮挡仿真。
