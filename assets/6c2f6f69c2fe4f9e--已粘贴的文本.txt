"""Explicit metric-depth/force adapter; use this loader for every inference."""
import json
from pathlib import Path
import torch
from torch import nn
from safetensors.torch import save_file,load_file

MODES=('rgb','force','depth','force-depth')
class DepthEncoder(nn.Module):
    def __init__(self):
        super().__init__()
        self.net=nn.Sequential(nn.Conv2d(2,16,5,2,2),nn.GroupNorm(4,16),nn.SiLU(),
            nn.Conv2d(16,32,3,2,1),nn.GroupNorm(8,32),nn.SiLU(),
            nn.Conv2d(32,64,3,2,1),nn.GroupNorm(8,64),nn.SiLU(),
            nn.AdaptiveAvgPool2d((4,4)),nn.Flatten(),nn.Linear(1024,128),nn.SiLU(),nn.Linear(128,18))
        # Start with the pretrained state's unused padding slots at zero.
        nn.init.zeros_(self.net[-1].weight);nn.init.zeros_(self.net[-1].bias)
    def forward(self,x):return self.net(x)

class DepthForcePolicy(nn.Module):
    def __init__(self,policy,mode='force-depth',near=.07,far=1.0):
        super().__init__()
        if mode not in MODES or not 0<near<far:raise ValueError('Invalid modality/range')
        self.policy=policy;self.mode=mode;self.near=near;self.far=far
        self.depth_encoder=DepthEncoder() if 'depth' in mode else None
        if policy.config.max_state_dim!=32:raise ValueError('Requires 32 internal state slots')
    def fuse(self,batch):
        state=batch['observation.state']
        if state.ndim!=2 or state.shape[-1]!=14:raise ValueError('Expected normalized [B,14] state')
        force=state[:,8:14] if 'force' in self.mode else torch.zeros_like(state[:,8:14])
        if self.depth_encoder is not None:
            depth=batch['observation.depth.left_wrist_m'];mask=batch['observation.depth.left_wrist_valid'].bool()
            if depth.ndim==3:depth=depth[:,None]
            if mask.ndim==3:mask=mask[:,None]
            if depth.shape!=mask.shape or depth.shape[0]!=state.shape[0]:raise ValueError('Depth/mask mismatch')
            mask=mask & torch.isfinite(depth) & (depth>=self.near) & (depth<=self.far)
            safe=torch.where(mask,depth,torch.full_like(depth,self.near))
            scaled=torch.log(safe/self.near)/torch.log(torch.tensor(self.far/self.near,device=depth.device))
            features=torch.cat([torch.where(mask,scaled,torch.zeros_like(scaled)),mask.to(depth.dtype)],dim=1)
            latent=self.depth_encoder(features.to(dtype=state.dtype))
        else:latent=state.new_zeros((state.shape[0],18))
        out=dict(batch);out['observation.state']=torch.cat([state[:,:8],force,latent],dim=-1)
        return out
    def forward(self,batch,**kwargs):return self.policy.forward(self.fuse(batch),**kwargs)
    def predict_action_chunk(self,batch,**kwargs):return self.policy.predict_action_chunk(self.fuse(batch),**kwargs)
    def reset(self):return self.policy.reset()
    def save_bundle(self,folder,pre,post):
        folder=Path(folder);folder.mkdir(parents=True,exist_ok=False)
        # Base file is nested intentionally: standalone stock loader omits the adapter.
        self.policy.save_pretrained(folder/'policy');pre.save_pretrained(folder/'policy');post.save_pretrained(folder/'policy')
        spec={'format':'g1_smolvla_depth_force/1','mode':self.mode,'near_m':self.near,'far_m':self.far,'state_dim':14,'action_dim':8,'internal_fusion':'8 normalized joints/gripper + 6 normalized raw wrench + 18 learned depth latent','depth_resize_hw':[128,224],'force_units':['N']*3+['N*m']*3,'force_frame':'unverified SDK sensor frame','tare':'unknown','gravity_compensation':'unknown','requires_custom_loader':True,'training_ready_for_robot_deployment':False}
        if self.depth_encoder is not None:save_file({k:v.detach().cpu().contiguous() for k,v in self.depth_encoder.state_dict().items()},folder/'depth_encoder.safetensors')
        (folder/'multimodal_config.json').write_text(json.dumps(spec,indent=2)+'\n')
    @classmethod
    def load_bundle(cls,folder,device='cuda'):
        from lerobot.configs.policies import PreTrainedConfig
        from lerobot.policies.factory import get_policy_class,make_pre_post_processors
        folder=Path(folder);spec=json.loads((folder/'multimodal_config.json').read_text())
        if spec['format']!='g1_smolvla_depth_force/1':raise ValueError('Unknown adapter format')
        cfg=PreTrainedConfig.from_pretrained(folder/'policy');cfg.device=device
        policy=get_policy_class('smolvla').from_pretrained(folder/'policy',config=cfg,strict=True)
        obj=cls(policy,spec['mode'],spec['near_m'],spec['far_m'])
        if obj.depth_encoder is not None:obj.depth_encoder.load_state_dict(load_file(folder/'depth_encoder.safetensors'),strict=True)
        obj.to(device)
        pre,post=make_pre_post_processors(cfg,pretrained_path=folder/'policy',preprocessor_overrides={'device_processor':{'device':device}})
        return obj,pre,post

def preprocess(raw,pre,device):
    # Keep depth fields outside stock LeRobot processors (which only know standard modalities).
    depth=raw['observation.depth.left_wrist_m'];mask=raw['observation.depth.left_wrist_valid']
    batch=pre({k:v for k,v in raw.items() if not k.startswith('observation.depth.')})
    batch['observation.depth.left_wrist_m']=depth.to(device=device,dtype=torch.float32)
    batch['observation.depth.left_wrist_valid']=mask.to(device=device,dtype=torch.bool)
    return batch
