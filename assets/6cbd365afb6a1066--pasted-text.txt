# 机器人端部署

**适用场景：** 生产环境部署，实时性要求高的应用

**特点：** 无网络延迟，通信开销最小

## 1. 连接机器人网络

1.1 开机后在网络选择界面连接WiFi





1.2 在Network界面查看机器人IP地址



**IP 用途说明**

此 IP 为后续部署 SDK 到机器人时需要输入的 IP 地址，外部也可通过 `ssh` 登录此 IP 在机器人上运行程序。同时，在进行 SDK 与机器人系统版本兼容性检查时，也可以通过该 IP 指定目标机器人：
```bash
galbot_sdk check-version [--robot-ip <IP>]
```

## 2. 部署SDK到机器人

2.1 在PC上执行部署脚本
```bash
cd GalbotSDK
./deploy_to_robot.sh
```

2.2 根据提示输入连接信息

- 用户名：`galbot`
- Orin IP地址：例如 `192.168.120.180`
- 密码：[REDACTED]

**部署结果**

动态库自动安装到：`/data/galbot/lib`

2.3 验证安装
```bash
ssh galbot@<机器人IP>
ls /data/galbot/lib | grep galbot_sdk
```

**预期输出**

显示 libgalbot\_sdk.so 和 libgalbot\_sdk.so.1.7.0

2.4 环境变量配置

**环境变量已自动配置**

使用 `deploy_to_robot.sh` 部署SDK时，安装脚本已自动配置环境变量并写入 `~/.bashrc`，重新登录或运行 `source ~/.bashrc` 即可生效。

如果运行程序时找不到 `galbot_sdk` 库，请执行：
```bash
export LD_LIBRARY_PATH=/data/galbot/lib:$LD_LIBRARY_PATH
export PYTHONPATH=/data/galbot/lib:$PYTHONPATH
export PATH=/data/galbot/lib/galbot_sdk/bin:$PATH
echo 'export LD_LIBRARY_PATH=/data/galbot/lib:$LD_LIBRARY_PATH' >> ~/.bashrc
echo 'export PYTHONPATH=/data/galbot/lib:$PYTHONPATH' >> ~/.bashrc
echo 'export PATH=/data/galbot/lib/galbot_sdk/bin:$PATH' >> ~/.bashrc
```

## 3. 运行程序

### 3.1 Python程序

3.1.1 传输python源码到机器人的Orin上
```bash
scp your_app.py galbot@<机器人IP>:/userdata
```

3.1.2 运行PYTHON程序
```bash
python your_app.py
```

### 3.2 C++程序

3.2.1 在PC上安装SDK

进入到SDK目录下执行安装脚本
```bash
cd GalbotSDK
./install.sh
```

3.2.2 在PC上交叉编译（aarch64）
```bash
cd examples/cpp/
mkdir -p build
cd build
cmake ../ -DCMAKE_TOOLCHAIN_FILE=../cmake/linux-aarch64-gcc940.cmake
make
```

3.2.3 传输可执行文件到机器人的Orin上
```bash
scp your_app galbot@<机器人IP>:/userdata
```

3.2.4 运行程序
```bash
ssh galbot@<机器人IP>
cd /userdata
./your_app
```

# PC端部署 - Ubuntu

**适用场景：** 开发调试，快速迭代

**特点：** 开发便捷，支持局域网远程控制

## 1. 物理连接

PC 通过以太网转接板与机器人相连。转接板用于把标准 RJ45 网线接口转换为机器人专用的以太网接口，使用步骤如下：

1.1 将网线一端插入转接板的 RJ45 接口，另一端连接到 PC 网口

1.2 将转接板的另一端插入机器人背部对应的以太网接口



连接完成后整体走线如下图所示：



## 2. 配置网络

### 2.1 配置PC网口IP

- IP地址：`192.168.1.99`（或同网段其他地址）
- 子网掩码：`255.255.255.0`

设置路径：**设置 → 网络 → 有线设置 → IPv4 → 手动**



验证配置：
```bash
ifconfig
```

**预期输出**

显示 `inet 192.168.1.99`



### 2.2 一键配置PC、XCU、HPU端IP

**前提条件**

PC、XCU、HPU 三者需能互相 ping 通

在SDK目录下执行 `configure_embosa_ip.sh` 脚本，配置PC端的IP（以 PC: 192.168.1.99、XCU: 192.168.1.66、HPU: 192.168.1.88 为例）：
```bash
./configure_embosa_ip.sh
```

脚本启动后依次提示输入以下信息：
```text
请输入配置的 PC IP: 192.168.1.99          # 必填
请输入配置的 XCU IP [默认 192.168.1.66]:  # 直接回车使用默认值
请输入配置的 HPU IP [默认 192.168.1.88]:  # 直接回车使用默认值
```

脚本将自动完成 PC、XCU、HPU 三端的 embosa IP 配置并重启各端 launcher。

## 3. 在PC上安装SDK

进入到SDK目录下执行安装脚本
```bash
cd GalbotSDK
./install.sh
```

**环境变量已自动配置**

安装脚本已自动在PC端配置环境变量，将以下内容写入 `~/.bashrc`：
```bash
source /opt/galbot/galbot_sdk/linux-x86_64-gcc940/setup.sh
```

重新登录或运行 `source ~/.bashrc` 即可生效。如果找不到 `galbot_sdk` 库，请重新执行安装脚本或检查 `~/.bashrc` 中的配置。

## 4. 编译程序

在PC上编译（x86\_64）
```bash
cd examples/cpp/
mkdir -p build
cd build
cmake ../ -DCMAKE_TOOLCHAIN_FILE=../cmake/linux-x86_64-gcc940.cmake
make
```

## 5. 运行程序

5.1 运行C++程序
```bash
cd /userdata  # 或程序所在目录
./your_app
```

5.2 运行Python程序
```bash
python your_app.py
```

**python相关库安装**

在运行python example时依赖一些库，所以请先运行下面的脚本保证相关库已安装：
```bash
cd GalbotSDK
./install_python_deps.sh
```

# Docker部署

**适用场景：** 需要与宿主机隔离的环境

## 1. 环境配置

- 需安装 **Docker** 与 **Docker Compose**
- 可参考 **PC端部署** 中第一、第二章节，完成网线连接、修改机器人`embosa_ip_config.json` 等配置

## 2. 获取镜像

示例：
```bash
docker pull galbot/galbot_sdk:1.8.0
```

可根据实际需要版本，替换galbot\_sdk:1.8.0中版本号

## 3. 启动容器

进入SDK产出中docker路径，执行run脚本即可启动镜像
```bash
cd GalbotSDK/docker
./run.sh
```

容器内已安装好SDK动态库与运行环境

# 版本兼容性检查

**SDK 版本**：安装在开发电脑或机器人上的 Galbot SDK 软件包版本。

**机器人 GBS 版本**：运行在 Galbot 机器人硬件上的系统固件版本。这两个版本必须兼容才能确保正常运行。

### 快速使用

运行兼容性检查工具验证 SDK 版本与机器人 GBS 版本是否匹配：
```bash
galbot_sdk check-version
```

该工具会自动检测两个版本并指示是否兼容。如果发现不匹配，会提供升级或降级建议。

更多选项请运行 `galbot_sdk check-version --help`。
