    05 · 仿真遥操¶

    MODULE 05

    用 GP001 控制 Physics Simulator 中的机器人

    介绍 Remote Control Lite 设备输入、G1/S1 控制映射、仿真执行和 Snapshot 记录 Example。

    1. 本章介绍什么¶

    仿真遥操是指操作者通过外部设备实时控制仿真环境中的机器人。本章使用 GP001 和 Remote Control Lite，把设备数据映射到 Physics Simulator 中 G1 或 S1 的手臂、底盘、Leg 和夹爪。

    对应源码目录：example/04_teleoperation/。

    本章介绍的基础功能包括：

    • 发现并打开 GP001 串口设备；
    • 从 remote_control_lite 读取设备数据帧；
    • 把设备输入换算成机器人控制目标；
    • 在 Physics Simulator 中逐步执行控制命令；
    • 显示头部、左腕和右腕三个 OpenCV 预览窗口；
    • 记录 Physics Snapshot，并调用 Render Simulator 回放。

    Example 使用的接口

    Example 展示 GP001 设备发现、数据帧读取、坐标与关节映射、Physics Simulator 控制、三相机预览和 Snapshot 记录。G1 与 S1 分别提供独立的场景和映射脚本。

    2. 仿真遥操的四层接口¶

    1设备读取 Remote Control Lite 输出双臂、摇杆、扳机和按钮状态
    2输入映射 把设备坐标、零位、方向和范围转换成机器人目标
    3仿真执行 位置/速度命令写入 Physics Simulator 中的机器人
    4状态记录 按仿真时间采样 Snapshot，退出时写入 HDF5

    这四层在源码中保持分开。Remote Control Lite 只负责提供设备帧；机器人怎样运动取决于映射逻辑、 机器人控制接口、MJCF actuator 和 Physics Simulator 的状态推进。

    为什么映射不是复制数组¶

    设备与机器人可能具有不同的关节零位、正方向、行程和坐标系。例如摇杆给出机体坐标中的前后/左右， 而 G1 MJCF 的三个底盘虚拟关节按仿真坐标表达；脚本需要根据机器人当前朝向转换速度。

    映射代码还包含关节限位、速度缩放、摇杆死区、夹爪开度和急停处理。这些都是当前 Example 的具体 实现，不是 Remote Control Lite 自动推导出的通用映射。

    3. 当前 G1 Example 的映射¶

    GP001 输入 Physics Simulator 中的 G1 控制
    左侧 7-DoF 机械臂 左臂 7 个 position actuator
    右侧 7-DoF 机械臂 右臂 7 个 position actuator
    右摇杆 底盘前后、横移和旋转 velocity actuator
    左摇杆前后 5-DoF Leg 的站起/下蹲目标
    左 LT / 右 RT 左/右夹爪主控关节开合
    急停 停止底盘并暂停当前关节指令

    G1 场景由 SceneConfig JSON 加载，包含机器人、桌子、可乐、箱子和三个 RGB 相机。场景内容与设备 映射是两个独立层次：00_generate_scene.py 负责场景，01_gp001_remote_control.py 负责遥操。

    4. 运行仿真遥操 Example¶

    cd example/04_teleoperation/g1
python 01_gp001_remote_control.py

    脚本优先通过 /dev/serial/by-id 查找 GP001，也可以显式指定串口：

    python 01_gp001_remote_control.py --port /dev/ttyACM0

    程序运行时打开 MuJoCo Viewer 和三个 OpenCV 相机窗口，并从启动开始记录 Snapshot。按 q 或 Ctrl+C 进入退出逻辑，将当前记录写入 HDF5。

    6. Snapshot 回放和视频脚本¶

    当前 Example 提供三个顺序入口：

    python 01_gp001_remote_control.py
python 02_render_snapshots.py
python 03_images_to_video.py

    它们分别负责仿真遥操与 Snapshot 记录、Render Simulator 回放与图片落盘、图片序列编码。默认输出结构：

    synthetic_data/04_gp001_remote_control/
├── snapshot/physics_snapshots.h5
├── head_camera/
├── left_wrist_camera/
├── right_wrist_camera/
├── head_camera.mp4
├── left_wrist_camera.mp4
└── right_wrist_camera.mp4

    不显示 Render 界面并取消观看节奏同步：

    python 02_render_snapshots.py --headless --no-realtime

    这些文件是 Example 展示的基础输出格式。项目实际采用哪些状态字段、相机、频率、编码和目录规范， 由数据与算法团队定义。

    7. 源码阅读顺序¶

    1. 00_generate_scene.py：生成 G1 遥操使用的场景 JSON；
    2. resolve_remote_port()：发现串口并检查设备可见性；
    3. create_simulator()：加载 SceneConfig，创建 Physics Simulator；
    4. apply_frame()：把关节、摇杆、扳机和急停输入写到机器人接口；
    5. chassis_velocity_in_world()：把机体速度转换成仿真坐标速度；
    6. Snapshot 记录逻辑：按仿真时间采样并在退出路径写入 HDF5；
    7. 02_render_snapshots.py：读取 HDF5，驱动 Render Simulator 三个相机。

    example/04_teleoperation/s1/ 使用 S1 机器人和独立场景，接口顺序与 G1 相同，输出目录为 synthetic_data/04_gp001_s1_remote_control/。两个 Example 不共用机器人场景和 Snapshot。

    本章介绍了 SynthNova 中的仿真遥操接口和 GP001 Example：Remote Control Lite 提供设备帧，映射函数 生成机器人目标，Physics Simulator 执行动作并记录 Snapshot，Render Simulator 回放三路相机画面。
