# 拆垛位姿后端 V0–V5-5 版本关系回顾

日期：2026-09-12。仅核对本地历史报告与源码；未重跑实验、访问机器人或服务。

## 编号口径

沿用 `history/bin_mesh_dimensions_flange_side_chat_20260908.md` 的回顾编号：
V0=FDP，V1/B=箱口矩形，V2=整体箱壁中心，V3/C=多平面侧壁。
这套编号不是所有 Python method 的版本后缀：整体箱壁 method 后缀仍为 v1，
多平面早期实现曾称 v2。scratch/geometry_v0.py.txt 是失败原型，不是本表的 V0。
历史侧聊只用于确认命名；状态和原理以执行报告与源码为依据。

## 阶段和关系

| 编号 | 实验名称与实现原理 | 与前序关系 |
|---|---|---|
| V0 | FDP / FoundationPose++，冻结 RGB、depth、mask、K、mesh 请求并归一化 6D pose | 独立参考后端；不是轻量代码的父版本，也不是真值 |
| V1/B | RGB 边缘反投影，候选平面内拟合固定 400×300 mm 箱口矩形，沿法向减半高求中心 | 替代后端探索；D01 因竞争箱沿平面拒绝 |
| V2 | 从深度局部法向选近竖直壁点，整体拟合固定矩形，以壁面高度范围约束中心 Z | 与 V1 并列；不是叠加在 V1 位姿之后 |
| V3/C | 分解多个侧壁平面，要求三面且包含相对面，检查有限面支持与高度区间交集 | 细化 V2 的建模方式；早期多平面 v2 经投影/支持复核修正为 v3；D02–D12 0/11 接受 |
| V4 finite_height（a） | 高度仅统计有限侧壁范围内的支持点 | 在 V3 上修正；2/11 中间通过 |
| V4 joint（b） | 增加相对两面和正交第三面联合初值 | 累加 finite_height；4/11 中间通过 |
| V4 surface（c） | 复核观测面的腔内/外侧朝向与固定外尺寸是否相容 | 累加 joint 门禁，候选位置不变；最终 0/11 |
| V5-0 | mesh 单位、轴、中心、哈希、派生裁切合同审计 | 模型准备；实物/服务端版本对应仍待验证 |
| V5-1 | 预计算高度截面、模型点和法向、启发式表面角色 | 继承 V5-0；共享模型资产，无逐帧位姿 |
| V5-2 | B 箱口、C/V4-joint、mesh 粗投影候选汇集和去重 | 初始化模块，不是各位姿的平均或分量拼接 |
| V5-3 | 4DoF 模型点到观测最近点距离、裁剪和 soft_l1 鲁棒优化 | 用 mesh 壳体替代固定外矩形拟合；保留旧候选作种子 |
| V5-3b | 投影范围、z-buffer 自遮挡、双向最近点拟合及触边/内外表面歧义门禁 | 改进 V5-3 拟合，与 V5-2 组合运行和部署 |
| V5-4 constrained_icp | 从 V5-2+V5-3b 最终候选开始，可见壳体 4DoF 双向 point-to-plane 多尺度鲁棒配准 | 叠加精修 |
| V5-4 direct_full_mesh_icp | 从同一个被选中的粗初值开始，使用全角色模型点直接 ICP | 绕过 shell-fit 优化的替代对照；不是从 shell-fit 最终位姿开始 |
| V5-5 A | 倾斜支持集追溯、投影与合成平面验证工具修复 | 验证工具阶段，不是完整位姿后端 |
| V5-5 B | 观测包围范围中心、PCA yaw、顶部法向生成初值，6DoF 可见壳体双向最近点优化 | 复用模型的独立原型；不是直接继承 V5-4 ICP 输出 |

V5-3 实际先完成，随后补齐 V5-2/V5-3b。V5-3 报告概括为 V4/B+C 初值，
但 `mesh_shell_fit.py:seed_poses` 实际调用 V4 joint 主候选和竞争候选；完整
B/C/mesh 汇集在 `v5_2_visibility.py:fuse_initial_poses`。计划中 V5-3 法向距离
描述也不等同于已实现代码：实际 fit_one 优化模型到观测的欧氏最近点距离。
V5-3b 改为双向；显式 point-to-plane ICP 模块在 V5-4。

## 已有结果的解释

- D02–D12：V5-3 和 V5-2+V5-3b 都为 9/11 通过各自探索门限，但集合不同：
  后者补出 D08 并拒绝 D03，D12 仍拒绝。不能理解为整体精度单调提升。
- V5-4 应引用 `_03` 批次；前两次有可见性问题并已被取代。受约束 ICP
  模型 p90 变化中位数 −0.02 mm，全 mesh +65.38 mm；侧壁法向不足以约束 Z。
- V5-5 B 最终 B14：7 场景运行完成，算法内部接受 4/7，设计验收通过 1/7，
  其中通过项为遮挡场景安全拒绝；整体未达标。后续 H 三帧离线 FDP 对照已做，
  V5-5 全部拒绝；不能仍说“从未做真实 H 对照”，也不代表 C 阶段通过。
- 当前部署后端为 V5-2+V5-3b。Orin、Docker、双腕对照属于工程/验证分支，
  不应编号为新算法版本。mask 和 raw/LingBot 消融属于输入因素实验。
- FDP 差异不是绝对误差；接受门禁不是准确率；D 数据已参与开发。
