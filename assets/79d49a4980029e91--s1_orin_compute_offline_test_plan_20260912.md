## 执行顺序与验收矩阵

| 顺序 | 工作与输入 | 预期与通过标准 |
|---|---|---|
| A 固定基线 | 记录镜像 ID、源码/模型/配置/输入哈希、资源参数；整理已有右 accepted、左 rejected 证据 | 测试清单逐项标记已有证据或待执行；不把本地测试等同镜像内实测 |
| B 正常功能 | 两个原有 bundle 为锚点；从归档追加有完整输入和确认来源的不同帧，目标至少左右各两个有效样本，不足则记录缺口 | 与同输入旧环境比较状态、原因、正式及诊断输出；中心欧氏差 ≤ 1e-6 m，矩阵元素最大差 ≤ 1e-6；不要求所有样本 accepted |
| C 输入校验 | 在独立副本逐项注入：缺文件、哈希错误、schema 错误、左右腕与帧名不符、非 base_link、错误深度单位/轴、图像尺寸不符、空 mask、NaN/Inf、非法 K/TF、路径越界 | 每例单一故障；入口失败、非零退出、不产生正式可用位姿；错误可定位。语义用例重新计算被修改文件哈希，避免只测到哈希拒绝 |
| D 结果合同 | 检查 B 的 accepted/rejected，并用缺模型内容等受控 fixture 触发后端异常；仅测试挂载副本 | accepted 中心与矩阵平移一致；rejected/error 正式位姿为空，拒绝原因/错误清楚，诊断候选单列；accuracy_validated、grasp_ready 均为 false |
| E 文件及失败恢复 | 已存在输出目录、不可写输出、运行中停止本测试容器，然后新 run ID 重跑 | 不覆盖旧目录；失败/中断不被判断为成功；留存日志和部分输出，新 run 可正常完成；不操作其他容器 |
| F 隔离与收尾 | 核验实际容器 inspect、挂载和资源限制；检查输入哈希、输出目录及回归差异报告 | 断网、非 root、只读根/输入、独立可写输出、无 SDK/控制锁/docker.sock 挂载；无 OOM；形成通过/失败/未覆盖清单 |

B 的补充帧是软件回归覆盖，不是独立精度测试集。原有重复运行记录沿用，
仅新增样本或代码变更需要相应复验。对照必须使用同一 RGB/depth/mask/K/TF、
模型及参数，不能重新请求 SAM3/LingBot 后再称同输入。
诊断候选只比较同一语义字段；字段缺失或不可比较必须记为覆盖缺口。

## 测试运行与证据要求

- 后续在获得当前 S1 访问授权后，于 Orin 上执行正式镜像验收；本地可先准备
  fixture 和报告工具。本计划不启动 SSH，不授权采集或运动。
- 测试驱动及断言放在镜像外；算法仍执行镜像内文件，不能把本地新源码覆盖
  `/opt/box-pose` 后声称 `_03` 通过。发现需要修复时保留 `_03` 失败记录，
  新建后续版本并重新执行受影响用例。
- 沿用 6 CPU、8 GiB 内存、256 PIDs 和 512 MiB tmpfs，串行运行。
  不进行耗尽宿主机磁盘/内存的压力测试。每例建议设 180 秒超时，仅清理本例容器。
- 每个用例使用独立输出父目录：当前启动器挂载的是输出父目录，不能传入含
  历史运行结果的宽泛父目录并宣称容器只可写本次结果。
- 保存 case ID、输入来源/变更、预期、实际状态、退出码、stdout/stderr、
  结果路径、镜像 ID、哈希、耗时、资源采样、OOM 状态和判定。
- 当前代码 accepted 退出 0；正常 rejected 和被捕获的后端 error 都可能退出 3；
  参数/加载失败通常退出 2。测试驱动必须联合结果 JSON 和退出码判断，不能
  将 3 全记作算法拒绝。写入异常/中断可能没有完整 JSON，外部驱动负责归档。
- `run_summary.json` 存在本身不代表成功；要求进程正常结束、结果文件完整且
  状态字段一致，防止中断留下的部分文件被下游消费。
- 日志中的 `robot_accessed=false` 等声明需结合入口审查和实际隔离配置，
  不能只凭自报字段证明隔离。
- 人工确认与源 mask 的绑定需追溯宿主机导出来源。当前 bundle 加载器校验
  文件哈希，但不独立复核完整确认凭证；此项列为进入全链路前的专项核验，
  不能声称 `_03` 已保证“确认后改 mask 必定被检测”。

## 完成定义与后续阶段

本轮交付测试矩阵、可重复测试驱动、fixture 清单、逐例日志和汇总报告。
必选 B–F 用例均符合预期才标记离线功能验收通过；缺陷或证据缺口逐项记录，
不事后放宽数值容差或算法接受门限。性能记录用于识别异常，不设置未经需求
确认的实时速度指标；历史内存数字只是周期采样值。

验收通过表示冻结 Observation 计算后端具备继续集成的工程基础，
不表示绝对精度、倾斜箱体、实时重复性或抓取已验证。

之后单列“冻结 capture → 服务响应回放/mock → ROI → 确认 → Observation”
文件接口实现及离线测试，覆盖超时、401、无候选及确认不匹配；修改镜像需
新版本。再进入真实 SAM3/LingBot 联调和宿主机单侧采集。当前计划不涉及
机械臂、夹爪、升降或底盘运动，也不切换旧 current。
