# π0.5夹爪多种子与单维噪声审计

入口：`pi05_deploy/scripts/audit_milk_gripper_noise.sh`。本脚本是推理审计，不是新夹爪head的训练脚本。

```bash
# 默认只预览，核对两个专家检查点身份和SHA-256
bash '/home/lsy03/文档/ChatGPT/VLA G1 项目/pi05_deploy/scripts/audit_milk_gripper_noise.sh' --dry-run

# CPU核对数据、相同归一化与验证窗口；不加载模型
bash '/home/lsy03/文档/ChatGPT/VLA G1 项目/pi05_deploy/scripts/audit_milk_gripper_noise.sh' --prepare-only

# 用户执行GPU离线审计，0次优化器更新
bash '/home/lsy03/文档/ChatGPT/VLA G1 项目/pi05_deploy/scripts/audit_milk_gripper_noise.sh' --execute
```

比较首轮1900步与续训阶段500步（累计2400）的专家权重；源权重、原数据和独立测试集保持原样。默认从9条验证示教分别取每组4个均匀起点、4个开闭转折起点，约72个候选去重后用于两个模型。转折定义为未来1秒SDK接受夹爪目标的开度跨度≥20mm。

默认种子预先固定为`20261009,42,1729,9`，噪声使用独立torch CUDA Generator生成，种子按`preset_seed + batch_index*100000 + global_row_index`定位。两个模型使用相同观察、同一份显式初始噪声，不依赖模型内部随机调用次数。种子名称与LingBot相同不意味着两个模型的噪声张量相同，跨模型只能比较各自受控结果。

每个种子运行normal和flipped两种条件。flipped**只翻转32维初始噪声中的夹爪坐标7**，观察和其余31维完全相同，程序逐元素校验；不把夹爪映射到LingBot的28号槽位。模型输出的其他关节可能因网络耦合而变化，这不等于测试改了其他输入噪声。

报告包括每个种子的首步夹爪误差、种子平均/最差误差、每窗口最差误差、同窗口预测跨度、张开/闭合混淆率、越界比例/幅度，以及配对符号翻转后的预测变化。全部保留未经裁剪输出，不能挑一个最好种子作为修复。

混淆率以目标≤20mm为闭合、目标≥80mm为张开；同时给出预测跨50mm分类边界的比例和严重跨到≤20/≥80mm另一极端的比例，中间目标仍计入连续误差。它们是诊断规则，不是实际抓取成功判据。

另用相同噪声，在` t=0.1,0.5,0.9 `测量teacher插值的flow误差，区分去噪监督表现和自由采样表现。这些值是归一化速度场MSE，不是毫米误差，也不表示训练只用了这三个时间点。

默认沿用官方10步积分与BF16网络计算、FP32专家参数；初始噪声与Euler状态为FP32。可另跑`--integration-steps 50`检查积分步数影响，但该参数不把整个网络切成FP32。

GPU执行前通过`nvidia-smi`检查GPU0，容器内生成噪声及每次加载模型前再次检查实际空闲显存。默认门槛为14 GiB（可通过`--min-free-gib`调整）；不足时直接退出，不停止其他任务。门槛是为模型和前向激活预留的保守预算，不能阻止其他进程在检查后申请显存。预览与CPU准备不检查GPU。减少窗口或种子数量不能解决模型加载时因并发占用导致的OOM。

更短的首轮探针：

```bash
bash '/home/lsy03/文档/ChatGPT/VLA G1 项目/pi05_deploy/scripts/audit_milk_gripper_noise.sh' --execute --per-episode 1 --seeds 42
```

每次新建`AUDIT_DIR`，位于`pi05_deploy/runtime/outputs/gripper_audits/`。输出`config.json`、`probes.json`、`initial_noise.npy`及哈希、两模型预测NPZ、`summary.json`、`REPORT.md`、`status.json`和源代码快照。每5个窗口显示进度。

Ctrl+C会退出推理、释放容器/GPU并保留已完成模型的输出。当前不提供精确断点续跑；重新执行会创建独立目录。某一模型完成但另一模型未完成时，summary状态保持running，不视为两模型比较完成。

本次只完成语法、预览、CPU数据准备和统计/单维干预测试；GPU审计由用户执行。结论只能支持进一步判断噪声敏感性，不会自动断言根因或启动重新训练。
