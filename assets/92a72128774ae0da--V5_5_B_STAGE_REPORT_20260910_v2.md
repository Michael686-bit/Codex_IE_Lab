# V5-5 B 阶段报告：倾斜感知 6DoF 原型（最终停点）

日期：2026-09-10。状态：**原型可运行，固定设计门槛未通过；C 阶段未开始。**

## 目标与范围

在 V5-2+V5-3b 4DoF 基线之外实现独立的倾斜感知 6DoF 实验原型，使用
`R = Rz(yaw) Ry(pitch) Rx(roll)`，从观测生成倾斜初值，使用可见性裁剪、
双向最近点残差、局部尺度归一 Jacobian 和 fail-closed 门禁。truth pose 只
用于 runner 评估，未进入估计器。本阶段没有真实 H01L～H03L 对照、FDP、外部
服务或机器人访问。

## 完成的实现

- `v5_5_tilt.py`：完整 6DoF 位姿、倾斜初值、可见 mesh shell、双向残差优化、
  ±80 mm 局部平移和 ±12° 局部角度边界、总倾角 <=15°、覆盖/残差/可观测性诊断。
- `config/v5_5.json`：固定配置和验收相关参数，未按真值结果放宽门限。
- `generate_v5_5_synthetic.py`：冻结 mesh 采样点的像素 z-buffer 合成 RGB-D，
  包含真值姿态、噪声、随机缺失和连续遮挡；truth 只保存在 evaluation-only 文件。
- `run_v5_5_batch.py`：输入哈希、源码哈希、候选/正式 pose、truth 误差、设计
  门槛、停止原因和红色真值/绿色估计叠加图。
- `tests/test_v5_5_tilt.py`、`tests/test_v5_5_synthetic.py`：覆盖旋转顺序、
  法向到 roll/pitch、语义几何、设计门槛和诊断图。

## 失败原因与停止决定

1. 当前观察由离散 mesh 采样点的像素 z-buffer 生成，未使用三角面完整光栅化；
   深度量化、可见面稀疏和 mask 覆盖共同造成中心偏差。
2. 双向最近点残差能恢复部分倾斜方向，但在 pitch 负向、组合噪声和连续遮挡
   时仍会收敛到错误局部解释；优化器完成不等于位姿正确。
3. 当前可观测性 Jacobian 在错误候选上也可能满秩，说明还需增加表面角色和
   对应一致性门禁；不能只用 rank/condition ratio 作为完整姿态可信度。
4. `ok` 是算法内部拟合门禁，truth 设计判定单独记录；本报告不把 `ok=true`
   或“优化完成”写成准确度通过。

按交接文件停止：不修改 truth 门限，不把失败场景改为留出成功，不进入真实
H01L～H03L、FDP 或抓取链，不继续调 ICP。
