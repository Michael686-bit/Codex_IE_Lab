## 目标、当前停点与首轮范围

主线为 V5-2+V5-3b 可见性拟合；V5-5 是待实现的 6DoF 实验分支。
目标是恢复有观测支持的倾斜，同时保留歧义/退化拒绝能力，不以接近 FDP
或增加接受数代替准确度验证。V3/V4 不继续开发，ICP 不继续调参。

已完成：三帧目标确认（右前箱，H01L=3、H02L=4、H03L=4），SAM3/LingBot/
ROI、FDP、4DoF/ICP 对照、启发式顶部点云拟合、三种简化平面合成测试。
V5 可见性仅 H02L 接受；H01L/H03L 因内外表面歧义拒绝。

倾斜数字是相对 base_link +Z 的线索，不是重力真值。FDP 高度轴约
7.50/8.61/7.28°；顶部点云拟合约 5～7°，依赖选点。
历史“验证完成”不表示已验证箱口身份或完整 6DoF。

## 1. 具体改什么

### A：证据与验证工具修复（首轮）

1. 修复 render_tilt_h01l_h03l.py。现实现重跑 RANSAC 生成投影，体素索引
   没按原顺序排序，而且 raw 渲染使用 raw 案例自己的 mask；数值验证则使用
   已确认的 LingBot mask。因此旧投影不能当作原数字的精确复现。
   新渲染直接读取保存的平面/支持点，禁止为了画图重新拟合；raw/LingBot
   都使用同一个确认 mask，保留源像素索引。旧输出不覆盖。
2. 扩展 validate_tilt_h01l_h03l.py 的证据输出：保存候选原点、单位法向、
   精确支持点/像素、体素选择顺序、阈值和随机种子、拟合前后支持集合。
   TLS 后重新检查法向限制、归一化平面扩展范围和内点；不能把未除 sqrt(N)
   的奇异值当作与点数无关的空间跨度。方位角按圆周量处理。
3. 把顶部高度分位当作敏感性分析，不把多个受截取偏差影响的平面中位数
   称为真实倾角。不靠更小残差确认箱沿身份；逐区域显示支持/缺失情况。
4. 为旧平面估计器补充回归：0°、5°、8°，正负方向、单轴/组合倾斜；
   狭窄条带、单线、两个竞争平面、缺面及离群点。现 synthetic 脚本只是
   随机平面，噪声是 XYZ 各向同性噪声、缺失是随机删点，不得称 mesh
   渲染、真实深度噪声或遮挡验证。
5. 新增 A 阶段报告和回归测试，记录证据不足的帧/区域；本阶段不修改 V5。

可以复用旧函数，不复制整套实现或重构无关模块。

  R = Rz(yaw) Ry(pitch) Rx(roll) 的约定。维持右手系、米制、几何中心原点。

  局部几何选择观测，并保留点的来源。模型点、法向、投影和遮挡必须使用同一 R。

- 新建真正的 mesh 合成观测：仅保留相机可见表面，用独立于估计器的

## 3. 如何验收

### A 验收

- 每张投影图和对应 JSON 的法向/原点/支持点来自同一份记录；支持点可回溯
  到像素、深度、K、TF。投影反投影数值误差 <=1e-6 m，保存值不因渲染变化。
- 同一 raw/LingBot 对照使用确认 mask 相同 SHA-256；输入和历史输出哈希不变。
- 原有 0/5/8° 场景固定种子回归全部报告，原法向误差门限 1° 不放宽。
  狭窄/单线和竞争平面必须输出退化/歧义，而非一个无条件“可信倾角”。
- 展示每帧每来源至少一个代表候选及变化曲线；明确平面身份是已确认、
  启发式还是未知。若真实身份仍未知，A 可以以“无法证实唯一箱口”完成，
  但不能自动把该法向当成 B 的可靠测量。
- A 完成：输出复核报告，不重跑已完成的外部服务，不开始真实运动。

### B 验收（以下是新实验设计门槛，不是已测性能/抓取要求）

- 旋转、法向、投影、语义中心与 180° 等价转换单元测试通过。
- 合成矩阵：roll/pitch=(0,0)、(±5,0)、(0,±5)、(±8,0)、(0,±8)、
  (5,5)、(-5,5)，yaw=0/45/90°，至少两个可见视角；每组固定真值和种子。
- 理想可观测场景：有效输出中心误差 <=2 mm、高度轴夹角 <=1°、对称旋转差
  <=1°；噪声场景（1/2 mm 光轴噪声、30% 随机缺失）设计目标 <=5 mm /2°/2°。
  报告全部场景，理想场景不能靠拒绝来凑通过；噪声有效场景接受至少 90%，
  所有被接受样本都必须满足对应误差界。未达标则 B 未通过，不放宽门限。
- 单面、窄条带、明显竞争解和连续遮挡导致的不可观测案例：正式 pose 必须
  拒绝；仅“部分遮挡”不能自动判为应拒绝，按剩余观测确定标签。
- 直立可观测控制组与原 4DoF 比较，不新增错误接受；精度变化逐项报告。
- 修改相关测试和既有测试通过；新增测试必须覆盖失败，不只验证代码返回值。
- B 通过后仍为实验版，不代表已验证真实箱体；未经 C 和独立测量不接抓取。

### C 指标

中心 XYZ/三维差、箱口中心、两侧短边中点、高度轴夹角、倾角/方向、180°
对称完整旋转差、候选/正式接受、拒绝原因和耗时。短边对应按统一对称变换，
不能每个点分别挑最近对应。只把 FDP 当参考；拒绝候选不进入有效位姿统计。
同一硬件报告旧版/新版耗时，不把本机耗时同远端 FDP 耗时当公平硬件比较。

## 4. 遇到什么必须停下

以下情况停止依赖它的步骤，先保存已完成工作与证据；无关的离线整理可以继续：

- 必需输入缺失、哈希冲突、左右腕帧或单位/轴合同不一致；不能重新标号绕过。
- 检测到其他任务同时修改已冻结的依赖：本次输出标记不可比较，不能混用版本。
- 只有通过更改已确认目标、强行指定内外壁、复制 FDP 初值或放宽固定门限
  才能继续。不得伪造确认或把运行成功当发布成功。
- A 投影与数值不一致未修复，或合成场景仍无法区分正常与退化：暂停后续阶段。
- B 未满足固定验收目标：记录失败，不进入 C 宣称改进；常规代码 bug 可在
  当前阶段修复，但修改模型假设/验收标准需要先报告并获取新的方向。
- 需要 SSH、联网推理、真实设备、服务重启/部署或额外付费依赖：本次交接只
  授权本地离线工作，停下说明缺什么。不复用旧 SSH/运动授权扩大本轮范围。
- 完成 A 或 B 的指定终点后交付；不要自行开始另一轮参数搜索或模型版本。
