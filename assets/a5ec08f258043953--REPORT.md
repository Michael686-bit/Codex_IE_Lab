# D12 mask来源核查 — 2026-09-29

结论：未发现C01那类mask来源混用。D12来自9月8日人工确认案例，selected_sam_index=3；确认文件哈希、原manifest哈希均核验通过。原mask、确认清单、跨数据集冻结mask及A0/A1/A2/A3/A4/A4-64记录的输入哈希一致。实际4090归档请求解码mask与原mask逐像素相同，IoU=1、差异像素0；RGB也逐像素相同。

mask覆盖图像右侧目标箱，范围x=931–1279、y=269–575，77626像素。图像1280×720，mask右边界接触图像最右列（32像素），存在视野截边；这是输入视野限制，不是来源错误。仅凭来源一致不能保证分割边界或绝对位姿完全正确，也不能把截边直接确定为位姿差的唯一原因。

相对4090，D12中心差：A0/A1/A2=0.258mm，A3/A4=5.667mm，A4-64=5.641mm。相同mask下加速候选方案出现更大差异，因此目前没有依据因来源问题替换D12 mask；如继续分析，优先检查候选选择/精修及截边观测影响。

本次仅本地读取与核验，没有新推理、没有修改D12输入或结果。逐项证据见audit.json与复现脚本audit.py。
