# Navigation learning workspace

This directory contains local learning code and experiments for S1 navigation,
SLAM, maps, mobile-base state, and offline visualization.

## Current experiment

`ros2_ws/src/s1_room0804_rviz/` is reserved for an offline ROS 2 Humble / RViz2
replay of the 2026-08-27 forward-1.0-m reachability refusal.  The replay will
show the room0804 map, the cleaned global point cloud, the recorded start and
goal, and the reported `omni_chassis_base_link` collision sphere.

## Safety boundary

- The RViz2 replay is offline and must not initialize Galbot SDK.
- It must not connect to S1, switch controllers, relocalize, or publish motion.
- Copied map assets under `data/` are local read-only inputs.
- A visual overlap in RViz2 is explanatory evidence, not proof that a local
  renderer exactly reproduces the vendor PNS ESDF implementation.
