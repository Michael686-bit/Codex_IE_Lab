# LingBot 可视化入门环境

入口：http://127.0.0.1:8010

2026-09-20 VERIFIED：独立镜像 `robotwin-sim:20260920`、容器 `robotwin-learning`，Python 3.10.18 + SAPIEN 3.0.0b1。使用 RoboTwin 官方 Aloha-AgileX URDF 和 mesh，真实 NVIDIA Vulkan 渲染。已有 LingBot 服务继续在 8006 端口运行。

## 第一课

1. 打开页面，看总览和顶部、左腕、右腕三个相机。
2. 拖动左臂/右臂滑块，松开后更新画面。单位为弧度；0.1 rad 约 5.7°。
3. 输入英文任务，点击“预测一次动作”。程序把当前真实渲染图像和当前关节状态发给本机 LingBot。
4. 看返回的 25 × 14 动作块和耗时。14 维顺序为左臂 6 关节、左夹爪、右臂 6 关节、右夹爪，不能当作 G1 双臂七关节。

画面中的机器人包含资产自带的主从机械臂结构，滑块控制前侧执行臂。当前是直接设置关节姿态的可视化练习；没有运行动态抓取控制循环，模型预测仅展示，不会自动执行。

## 验收与边界

- 场景渲染成功：`output/scene.png`。
- 浏览器预测按钮实测成功：输出 `(25, 14)`，数值全部有限，约 378 ms；API 测试约 386 ms。
- 模型 + 渲染同卡运行实测总显存约 14.6 GiB，剩余约 8.9 GiB（含桌面等其他进程）。
- 预测报告：`output/policy-preview.json`。
- 这是使用官方资产搭建的简化 SAPIEN 学习场景，**不是完整 RoboTwin benchmark**，不报告抓取/叠放成功率。没有安装该 benchmark 的全部训练、CuRobo、点云和 XPolicyLab 依赖，也没有下载全部物体和随机背景。
- 后续完整任务应使用与 LingBot 评测客户端兼容的 RoboTwin 版本，补齐依赖和任务资产，再运行闭环并记录视频与任务成功判断。
- 无 G1 网络连接、设备挂载或真机动作。

## 启动与停止

在本目录运行：

```bash
bash run.sh start
bash run.sh status
bash run.sh logs
bash run.sh stop
```

`start` 会重用已有容器，可在 `stop` 后再次启动。Docker 服务和 NVIDIA Container Toolkit 为前提。推理按钮还需要现有 `lingbot-vla-v2-local` 服务在 8006 端口运行。

该镜像复用已存在 LingBot 镜像的只读基础层，新增 Python 3.10 虚拟环境；不会修改现有 LingBot 容器或其 Python 3.12 环境。只监听本机 8010。源码和资产版本记录见 `source-lock.json`；下载的资产保留在 `cache/`。
