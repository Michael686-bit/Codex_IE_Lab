# 数据与板到箱体安装关系审计

日期：2026-09-28。仅使用本地冻结文件，无机器人、SDK或外部推理；未修改已有参考位姿及算法。

## 结论

32帧、raw/LingBot共64条件、320输入文件哈希核验通过。11帧参考的矩阵组合、相机内参/TF及原图来源均一致；C01/C08没有板位姿，其余D/H/F共19帧没有本评估使用的独立参考。因此21帧仍不能用于绝对精度验收。代码链一致不等于安装关系已被实物验证。

高度推导一致：实物最低点0、内底面12、板下表面12、印刷面14、中心86、最高点172mm，所以板面到中心72mm。未改动该高度。

## 水平关系的具体问题

### 1. 原OBJ原点与箱体中心未完整区分

原`r03/summarize.py`在OBJ原点处向正X、正Z方向求交，得到181.446400、130.569699mm；假定正负方向对称，将其用于箱体中心到接触面的距离。当前变换因此为：

`t_board_from_box = [171.446400, 59.430301, 72.000000] mm`。

但原OBJ包围盒中心并非X/Z零点：raw X=-0.842403mm、raw Z=+0.073982mm。算法使用的中心化语义坐标映射包含X平移+0.842403mm、Y平移-0.073982mm。旧水平公式没有显式完成这一步，也没有实际检测A角所在的负X侧。

这属于确定的坐标/对称假设问题，量级小于1mm；不能单独解释全部照片中的偏差，也不代表应该只补一个常数后就认定真值正确。

### 2. 板的新高度与旧取样截面不一致

旧水平数值来自模型内底面上方2mm的截面；后来只把板到中心的Z改成72mm，XY仍沿用旧值。将同一个175mm模型中心放在实物86mm处时，模型内底面约为实物显示Z=1mm，板下表面却为Z=12mm，二者差约11mm。

本次在实际展示的板下表面、中层、印刷面三个高度直接求交，得出：

|截面高度（实物显示轴）|负X侧中央内壁距中心|正Y侧中央内壁距中心|
|---|---:|---:|
|板下表面12mm|180.792589mm|130.684241mm|
|板中层13mm|180.813536mm|130.705188mm|
|印刷面14mm|180.834483mm|130.726135mm|

这些是原模型的几何数值，不是实测箱体尺寸。模型外高175mm，实物外高172mm，模型内底结构也不同，不能靠平移同时对齐所有表面。

### 3. A角不能由中央截面代替

当前板A角在箱体语义坐标中为(-181.446400,130.569699)mm。以300×200mm完整矩形板、板边不倒角为假设，在两条贴合边各距端点2mm之外采样，对原mesh求首次内壁交点：

|高度|负X板边相对内壁间隙范围|正Y板边相对内壁间隙范围|
|---|---:|---:|
|12mm|−5.265～−0.654mm|−5.633～+0.115mm|
|13mm|−5.216～−0.633mm|−5.561～+0.135mm|
|14mm|−5.168～−0.612mm|−5.488～+0.156mm|

负值表示该板边越过射线检测到的mesh内壁位置。较大差异集中在A角附近的倒角过渡区。该诊断没有证明实物碰撞：实物角形、板角裁切和模型与实物差异尚未核实。表中为离散采样范围，不是连续几何极值或完整碰撞检测。

![截面与当前板轮廓](mesh_contact/sections.png)

青色为三角mesh的精确平面截线，红色为当前假设的板轮廓。左上使用旧模型底面上方2mm的截面（统一采用当前模型中心高度显示）；其余三张对应板厚范围。

## 参考不确定性的影响

对现有11帧raw结果，仅假设板到中心的三个平移分量各有±1mm变化，测试8个组合角点，全部组合仍通过10mm位置门限的帧数由11降至10；±2mm时为7。此为假设扰动敏感性分析，不是实测误差、概率或置信区间，也不是建议据此调参考以改善算法成绩。

## 下一步与当前决策

1. 保留现有参考为`provisional`，不把名义XY安装称为独立真值；不按本次几何推导直接重写历史成绩。
2. 先确认A角的真实接触形状：板角是否裁切/倒角、两边的实际接触段、实物圆角是否与mesh一致。不能只凭“无间隙”推出完整矩形与两条延长直线的交点接触。
3. 若确认mesh接触几何可用，使用中心化坐标，在板厚全范围内计算对应接触位置；输出新版本候选并与旧版本对照。
4. 若模型不代表实物接触几何，需要实测板到箱体中心的安装关系或接触平面位置；mesh不能替代缺失的实测。
5. 安装参考可信度确定后，继续算法独立精度验证。缓存LingBot生成时间仍需单独评估。
