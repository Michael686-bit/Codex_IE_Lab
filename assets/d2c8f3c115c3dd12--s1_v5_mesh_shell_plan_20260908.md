## 决策与依据

V5 应使用 4317 mesh，但第一目标不是直接运行通用 ICP，而是从 mesh 生成与
高度、表面角色和相机可见性相关的简化几何模型。V4-c 的主要问题是把箱沿
最大外形 `400 × 300 mm` 当成所有侧壁截面的固定间距；冻结 OBJ 已证明箱身
中央截面明显更窄且随高度变化。

因此建议主路线为：

```text
冻结 mesh 与语义坐标审计
        ↓
预计算法兰、外壁、内壁、筋条及随高度变化的截面
        ↓
B 箱口候选 + C 多侧壁候选
        ↓
可见表面对应与 4DoF 壳体拟合
        ↓
受约束、可见性裁剪的 point-to-plane ICP 对照/精修
        ↓
箱体中心、方向、箱口范围与短边参考
```

“直接全 mesh ICP”仅保留为对照。它可能把内壁、外壁、法兰或筋条配到错误
位置，同时获得较低残差，不能作为默认主方案。

## V5-0：模型合同与资产审计

目标：确认本地 mesh 真正代表当前 4317 实物及预期 FDP 模型，而不只是假设。

1. 固定 mesh SHA-256、米制单位、原始轴、中心化规则和
   `T_fdp_mesh_from_4317_semantic`。
2. 检查连通分量、退化/重复三角面、法向一致性、开边和是否封闭。
3. 分析不同高度和不同切向位置的截面，覆盖中央壁、角部、把手、加强筋和
   顶部法兰；现有中央射线结果只作起点。
4. 将表面划分为 `rim/flange`、`outer_shell`、`inner_shell`、`rib/handle`、
   `bottom/unknown`，并为自动分类保留人工可视化审阅。
5. 若无法证明本地 mesh 与实物/当前服务端版本一致，标记 **待验证**，不把
   mesh 拟合误差称为实物位姿误差。

交付物：模型合同 JSON、带语义颜色的 mesh/点云、截面查找表、资产哈希、
审计图和失败说明。

## V5-1：随高度变化的壳体模型

从 mesh 预计算轻量模型，而不是每帧重新遍历完整三角网格：

- 高度层 `z` 对应的内/外长宽边界；
- 每层四个方向的候选面位置、法向和表面角色；
- 顶部法兰/箱沿的外轮廓与内开口；
- 筋条和把手区域的可选排除 mask；
- 2～5 mm 分辨率的模型点/法向，或二维截面距离场；
- 观测不到的表面不计惩罚，背面和被遮挡面不产生对应。

先建立三级模型：粗壳体、箱沿/法兰、筋条细节。只有冻结深度确实能分辨细节
时才启用筋条层，避免高频 mesh 几何放大深度噪声。

## V5-2：B + C 多候选融合

输入保持为每帧确认的最终 ROI mask、LingBot 深度、K 和捕获 TF：

1. B 分支提供箱口平面、外轮廓/内开口和 yaw 候选。
2. C/V4 分支提供侧壁方向、相对面、中心和高度区间候选。
3. 不提前选唯一解；将两类候选转成同一 4317 语义坐标合同。
4. 每个候选标明哪些量来自观测、mesh 先验或直立约束。
5. 以 mesh 截面检查每个观测面可能对应内壁、外壁、法兰或筋条；保留所有
   评分接近但空间位置不同的解释。

V5 的核心优化变量先限定为 `x/y/z/yaw`。roll/pitch 保持重力直立约束；若
观测倾斜超限则拒绝，而不是强制压平后发布。

## V5-3：纯壳体拟合基线

在加入 ICP 前先实现可解释的壳体拟合：

- 残差使用观测点到其候选 mesh 表面的法向距离；
- 对法兰、内壁和外壁分别统计支持点、覆盖率及残差；
- 使用鲁棒损失和裁剪，记录被排除点及原因；
- 要求至少两个方向、足够高度/切向覆盖，以及可观测的中心自由度；
- 不允许同一个观测平面同时支持两个物理面；
- 对 180° 对称解和内外壳解释分别评分；评分接近时拒绝。

这个分支是 V5 的主要基线。只有它能提供可解释初值，才能判断 ICP 的增益。

## V5-4：受约束 ICP 对照

首轮执行结果见 [V5-4 报告](../experiments/20260907_bin_rim_pose/V5_4_ICP_AB_REPORT_20260909.md)。
在 D02–D12 上受约束 ICP 相对 shell-fit 的模型 p90 中位数只变化 −0.02 mm，
6/11 帧改善、5/11 变差，且 11/11 帧没有足够 z 法向支持；直接全 mesh ICP
作为负面对照明显恶化。因此
下一轮应先补充可信箱沿/水平面观测和表面角色对应，再决定是否继续调 ICP。

在相同候选上比较三种后端：

1. `shell_fit`：纯壳体拟合；
2. `shell_fit + constrained_icp`：只优化 `x/y/z/yaw`；
3. `direct_full_mesh_icp`：从相同粗初值运行的负面对照，不作为默认输出。

ICP 要求：

- 使用可见性裁剪后的模型表面和观测点；
- 多尺度体素、鲁棒核、法向一致性和最大对应距离；
- 180°、内/外壳和多个 B/C 初值分别运行；
- 保存迭代前后中心、yaw、短边参考、fitness、RMSE、内点率、覆盖率、耗时；
- ICP fitness/RMSE 只作拟合诊断，不能单独通过准确度门禁；
- 若 ICP 使候选进入另一表面角色、增大短边差异或缩小多解差距不足，则拒绝。

## 真值与准确度实验

若要回答“中心误差多少毫米/准确率多少”，必须新增独立参考：

1. 优先使用固定在目标箱上的 AprilTag/标定板，并测量
   `T_tag_from_4317_semantic`；标签尺寸、安装误差和 PnP 误差进入预算。
2. 或用外部测量/人工治具记录箱体中心、yaw、箱口四角和两个短边参考点。
3. D10 画面中的棋盘格当前没有尺寸、相机到板及板到目标箱变换，不能直接
   当作真值；还需确认它是否安装在本帧所选物理箱上。

建议的**设计目标**（不是当前实测或性能承诺）：

- 箱体中心 XY 误差不超过 10 mm；
- 箱口中心 Z 误差不超过 8 mm；
- 180° 对称 yaw 误差不超过 2°；
- 两个短边几何参考点位置误差不超过 10 mm；
- R01～R03 不允许错误接受；
- 最终阈值需由夹爪、手眼标定、机械臂和接触几何误差预算调整。

小样本不得给生产成功率。报告逐帧误差、p50/p95、拒绝率、错误接受率，并给出
置信区间或明确样本不足。

## 分阶段实验矩阵

### E1：模型预计算正确性

用合成语义位姿生成可见 mesh 点云，加入已知噪声、缺面和遮挡。验证截面查询、
内外表面标签、坐标变换和 `x/y/z/yaw` 恢复；错误 mesh 单位/轴应被拒绝。

### E2：D01～D12 离线回放

固定输入、阈值和随机种子，对比 V4-c、V5 壳体拟合、V5+ICP、直接 ICP。
逐帧检查候选数量、表面对应、中心/yaw、短边参考和耗时。FDP 只在存在同帧
保存结果时列为参考差异，不作为真值。

### E3：raw/LingBot 单变量消融

固定同一确认 mask、K、TF 和 mesh，只切换 raw/LingBot 深度。比较可见表面、
候选变化、拒绝原因和最终误差；不把 raw/LingBot 各自重新选中的不同实例混入。

### E4：独立真值与留出验证

冻结算法后采集带参考的 H01/H02/R01～R03。分别报告有效帧接受、拒绝帧错误
接受、中心/yaw/短边误差及 p50/p95。留出失败先记录新失败模式，再决定是否
开始下一版本；不能改完参数后沿用同一留出成绩。

### E5：OrinX 性能

在确认具体 OrinX 型号、系统和功耗模式后，记录壳体预计算大小、CPU/GPU、
内存、单帧和整链 p50/p95。优先 CPU 小规模点集、缓存模型点/法向和限制候选
数，再决定是否需要 CUDA ICP。

## 阶段门禁与停止条件

进入受约束 ICP 前，壳体拟合必须在合成数据上正确恢复已知变换，并在真实帧中
输出可解释的表面对应；否则 ICP 只会掩盖模型错误。

进入抓取规划前，必须具备独立参考、达到短边点误差目标、拒绝样本无错误接受，
且正式 schema 明确 `accuracy_validated=true`。V5 中间输出保持
`grasp_ready=false`。

若 mesh 与实物不匹配、深度无法区分壳体表面，或多解长期无法消除，则停止继续
调几何/ICP，改用贴标参考、专用关键点或多视角观测。
