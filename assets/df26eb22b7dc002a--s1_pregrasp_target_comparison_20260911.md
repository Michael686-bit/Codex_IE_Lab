## 不能直接移动的原因

两个 JSON 的 `executable=false`。当前报告仍明确阻塞：

- 没有针对这两个新目标运行 S1 IK、关节限位和奇异位形检查；
- 没有运行双臂同步和 GE103 工具碰撞检查；
- 没有把真实箱体、邻箱和现场障碍加入碰撞场景；
- 当前 GE103 工具/规划服务状态没有为本次运动重新核验；
- 当前 V5/FDP 差异不是绝对误差，FDP 也不是独立真值；
- 实际箱体和 mesh 的内外表面身份仍未独立确认。

因此这些候选可以用于离线审阅、IK/碰撞检查和轨迹预览，不能直接传给
`set_joint_positions`、IMC 执行器或夹爪控制器。移动前还必须确定使用 V5 还是 FDP、
只动右臂还是双臂、夹爪目标宽度、接近速度、停止条件和物理急停状态；真实运动
需要新的逐步确认。
