# LingBot-Depth 本地部署

本目录独立于 LeRobot / ROS 环境，使用 Python 3.10 虚拟环境 `.venv`。
源码：https://github.com/Robbyant/lingbot-depth
源码版本：f3a237e434ae987bc38281476d6cfb5df3e4d739
模型：robbyant/lingbot-depth-pretrain-vitl-14-v0.5
权重来源：https://modelscope.cn/models/robbyant/lingbot-depth-pretrain-vitl-14-v0.5

## 运行官方样例

```bash
cd '/home/lsy03/文档/ChatGPT/VLA G1 项目'
./lingbot_depth/run_example.sh --device cuda
./lingbot_depth/run_example.sh --device cuda --example 1 --output ../results/example1
```

默认结果保存在 `lingbot_depth/results/example0/`，包括深度补全前后对比图、以米为单位的 NumPy 深度数据和 PLY 点云。

## 使用自己的数据

将已对齐的 `rgb.png`、`raw_depth.png`、`intrinsics.txt` 放入同一个目录。
RGB 为彩色图片；原始深度为 16 位 PNG，官方样例默认单位为毫米（除以 1000 转米）；内参是以像素为单位的 3×3 矩阵文本。
用 `--example /绝对路径/数据目录 --output /绝对路径/结果目录` 指定。
输入深度与 RGB 应对应同一时刻、同一视角，并使用该分辨率下的内参。

## 隔离与资源

- 虚拟环境不继承系统 Python 包，不修改已有 LeRobot 环境。
- 官方固定 torch 2.6.0 和 xformers 0.0.29.post2；CUDA 运行库随 pip 依赖安装，不必重新安装系统 CUDA。
- Python 依赖隔离不等于 GPU 资源隔离：多个程序仍共享显存和算力。
- 启动前可用 `nvidia-smi` 检查空闲显存；首次运行时间不能当作稳定实时帧率。
- 默认从本地 `models/model.pt` 加载，已下载权重后不需要在线访问模型仓库。
