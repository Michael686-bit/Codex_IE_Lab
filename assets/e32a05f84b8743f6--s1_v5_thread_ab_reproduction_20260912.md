## 唯一变量与运行顺序

A 使用镜像原有默认线程环境，B 在 docker run 中增加：

```bash
--env OPENBLAS_NUM_THREADS=1 \
--env OMP_NUM_THREADS=1 \
--env MKL_NUM_THREADS=1 \
--env NUMEXPR_NUM_THREADS=1
```

先记录镜像默认环境，避免把“没有新增覆盖变量”误称为库实际线程数已知。
预运行 A/B 各一次，单独保存，不计入正式统计。
正式运行五个配对：AB、BA、AB、BA、AB，共 10 次，串行执行。
每次使用独立子目录保存命令参数、退出码、stdout/stderr 和算法原始输出。
每次最长 180 s，超时只停止本次测试容器，保存部分结果。
按既有耗时估计计算约 5 分钟，含检查及归档预计 5–10 分钟。
