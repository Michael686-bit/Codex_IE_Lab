真正省在哪里：每轮精修的候选数

候选 = 箱体可能的一个姿态；轮次统一为 3 轮
A0 原版
252 → 252 → 252
全部候选走完三轮。
A1 → A2
252 → 252 → 252
A1：等价 XYZ 采样、去掉无用日志计算。
A2：再加微批次 64、cuDNN 算法选择；候选总数不变。
A3 分阶段筛选
252 → 16 → 16
第一轮后评分，只保留 16 个继续计算。
A4 快速版
64 → 16 → 16
先按箱体近直立偏好，从 252 个选 64 个；再筛到 16 个。
不把 roll / pitch 强制归零；需要匹配的相机外参。
A4-64
64 → 64 → 64
保留更多候选，以计算量换取更宽的搜索范围。
