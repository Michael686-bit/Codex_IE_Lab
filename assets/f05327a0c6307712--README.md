# 13 帧 raw/LingBot 三版本 FDP 对照

本目录整理 13 帧标定板活动集在两种深度分支下的原始 Orin、v9 exact 和 v9 fast 结果。

| 版本 | 数据覆盖 | 正式重复 |
|---|---|---:|
| 原始 Orin | 13 × raw/LingBot | 每条件1次补跑 |
| v9 exact | 13 × raw/LingBot | 每条件1次补跑 |
| v9 fast | 13 × raw/LingBot | 每条件5次 |

三者均使用同一 Orin 冻结 bundle、同一 mesh、252候选和2轮精修；没有 SDK、相机、网络感知服务或运动调用。
`results_table.csv` 是逐帧逐分支表，包含 XYZ、RPY、相对原始 Orin 的 exact/fast 差值和执行时间。
RPY 使用 `scipy Rotation.as_euler('xyz')`，角度差包装到 `[-180°,180°)`。

三版本正式时间汇总：原始 Orin 全体中位数 6.903 s，v9 exact 4.168 s，v9 fast 2.893 s。
v9 exact 26 条件与原始 Orin 的 XYZ/RPY 完全一致；v9 fast 的 raw 分支中心差中位数
5.44 mm、P95 83.81 mm，LingBot 分支中心差中位数 6.16 mm、P95 16.20 mm。
完整字段说明见 `results_table.csv` 与 `table_summary.json`。

初步结论：v9 fast 速度约2.9秒，但三版本位姿一致性没有通过；异常诊断显示原始 Orin 与 v9 exact
逐帧一致，而 v9 fast 在部分 raw 条件出现几十到百毫米/度级变化。v9 fast 不应直接生产接入。
原始 Orin 与历史4090的差异另有运行时/服务版本边界，不能把4090当作独立真值。
