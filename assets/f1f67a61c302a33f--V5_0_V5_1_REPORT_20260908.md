# V5-0/V5-1 执行记录：Mesh 壳体模型建立

日期：2026-09-08。状态：V5-0、V5-1 完成；V5-2 纯壳体拟合和 ICP 尚未开始。

## 本阶段完成内容

基于冻结的 `EU4322_midcut_target175mm.obj` 派生文件建立了一个本地、可复现的
mesh 壳体模型：

- SHA-256：`adb0d1cf4ee3cc885641ce5e473efb31de4d80323e7665ec50fa5aaabbcc991b`；
- 832 个顶点、1,621 个有效三角面；
- 原始轴明确记录为 X=长、Y=高、Z=宽；语义轴记录为 X=长、Y=宽、Z=高；
- 高度步长 5 mm，生成 36 个高度层、72 条长/宽方向截面记录；
- 预计算三角形中心、法向、面积和表面角色，供后续拟合缓存使用；
- 表面角色目前由高度带和法向/径向关系启发式推断，不是厂家标签。

当前启发式类别计数：

| 类别 | 三角面数 | 面积 (m²) |
|---|---:|---:|
| `rim_flange` | 149 | 0.0483 |
| `outer_shell` | 356 | 0.1800 |
| `inner_shell` | 229 | 0.2503 |
| `bottom_flange` | 81 | 0.0271 |
| `rib/unknown_surface` | 444 | 0.3139 |
| `central_cut_seam` | 362 | 0.0030 |

其中 `central_cut_seam` 被单独保留，避免后续 ICP 把派生 mesh 的人工裁切接缝
误当成真实箱体结构。

## 随高度变化的截面结果

中央射线的首/末交点对只用于模型审计和候选初始化，不是实物测量。可用截面
范围如下：

| 方向 | 内层跨度范围 | 外层跨度范围 |
|---|---:|---:|
| 长向 | 362.953–372.360 mm | 366.821–399.797 mm |
| 宽向 | 261.200–270.928 mm | 265.439–299.987 mm |

多数高度层是简单两层交点，但法兰/复杂结构处会出现多次交点。结果确认：
“最大包围尺寸 400×300 mm”与箱身中部的实际截面不是同一个几何量。模型的
顶部、底部结构也不能简单镜像；当前 mesh 本身带有
`central-height cut/collapsed` 注释，完整实物 CAD 对应关系仍待厂家或现场确认。

## 验证与边界

43 项原有 v4/v3/batch 测试以及新增 3 项 mesh 模型测试通过，共 46 项；模型
构建不访问网络、不连接机器人、不调用 FDP/ICP。模型角色是启发式假设，不能
直接作为内外壁真值；mesh 与 4317 实物、当前 FDP 服务端 mesh 是否同一版本仍
待确认。

本阶段没有输出箱体位姿，也没有生成抓取目标。下一阶段先用合成语义位姿验证
截面查询和 `x/y/z/yaw` 恢复，再在 D01–D12 上实现纯壳体拟合，最后才比较
受约束 ICP 与直接完整 mesh ICP。
