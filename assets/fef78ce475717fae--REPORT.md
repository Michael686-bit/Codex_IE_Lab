# 以4090远程FDP为基准的A0–A4对比报告 — 2026-09-22

**结果：A0 23/28帧通过；A1 23/28帧通过；A2 23/28帧通过；A3 22/28帧通过；A4 23/28帧通过。所有Orin版本均有相对4090超限的帧。**

本报告将同帧4090远程服务的正式输出设为唯一比较基准，重新计算全部差距和阈值通过率。4090是选定参考，不是独立真值。仅对已有结果进行本地重算，没有重新推理或访问机器人。

## 数据与计算规则

D01–D12右腕12帧、H01L–H03L左腕3帧、活动ChArUco13帧（左8/右5），共28帧，左11/右17。ChArUco原16帧中活动集保持13帧，不因本次结果删帧。统一LingBot分支，各版本每帧1预热+5正式；统计各140次正式结果，预热不计入。

每条算法输出对同帧4090的5条正式输出分别比较，各指标取最坏值，再统计最小/中位/最大。已验证各版本同帧重复矩阵一致，因此不会因选取哪次参考而改变结果。XYZ是base_link坐标系下绝对位置差；中心为三维欧氏距离。roll/pitch/yaw采用XYZ Euler逐轴包装差的绝对值，未用对称旋转指标替换逐轴判定。中心≤10mm且三个角度各≤4°才通过；一帧5次全部通过才计为通过帧。

## 结果解释

以4090为基准后，A0–A4均未达到全部28帧的中心≤10mm、逐轴≤4°要求。之前“A4全部通过”的结论仅针对A0基准，不能迁移到4090基准。A4耗时仍全部小于1秒，但相对4090的位姿差仍有超限。

4090当前3轮精修，Orin为2轮；远程API将原float32米深度量化为uint16毫米PNG，最大单像素变化约0.999987mm。远端源代码、权重及mesh内容哈希尚未核验，且Torch/CUDA版本不同。因此该报告比较实际部署输出的一致性，不能把差距单独归因于显卡，也不能据此断言哪个输出更接近真实位姿。A4的竖直偏好与已有开发数据范围仍适用。
