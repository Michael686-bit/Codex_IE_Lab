项目里没保存具体 IP 和用户名。SSH 命令格式是：

```bash
ssh 用户名@S1的IP地址
```

```bash
ssh galbot@192.168.1.100
```

如果使用非默认端口：

```bash
ssh -p 端口号 用户名@S1的IP地址
```
