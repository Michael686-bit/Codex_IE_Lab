## 4. 助手

确认了，当前显卡确实是 **NVIDIA GeForce RTX 4090**，PCI ID 为 `10de:2684`。

目前状态：

- 系统：Ubuntu 22.04.4 LTS
- 内核：`6.5.0-18-generic`
- 当前驱动：开源 `nouveau`
- NVIDIA 专有驱动：未安装
- `nvidia-smi`：不存在
- Secure Boot：已关闭，不会阻碍驱动加载
- 系统推荐驱动：`nvidia-driver-595`

可通过下面的方式安装：

```bash
sudo apt update
sudo ubuntu-drivers install
sudo reboot
```

重启后检查：

```bash
nvidia-smi
```

所以你的记忆没错：是 4090，只是现在确实没有安装 NVIDIA 官方驱动。安装会修改系统并需要重启，我暂时没有替你执行。

## 6. 助手

按 Ubuntu 当前推荐版本安装：

```bash
sudo apt update
sudo apt install nvidia-driver-595
sudo reboot
```

重启后验证：

```bash
nvidia-smi
```

正常会显示 RTX 4090、驱动版本和显存信息。不要使用 NVIDIA 官网的 `.run` 安装包；Ubuntu 软件源版本更容易维护。如果安装时报错，把完整输出发给我。

## 7. 用户

现在我还在安装ros2，驱动是否能同时安装？

## 8. 助手

不建议同时安装，尤其是 ROS 2 正在通过 `apt` 安装时。两者会争用 `apt/dpkg` 锁，通常会报：

```text
Could not get lock /var/lib/dpkg/lock-frontend
```

建议顺序：

1. 等 ROS 2 安装命令完整结束。
2. 确认没有报错。
3. 再安装显卡驱动：

```bash
sudo apt update
sudo apt install nvidia-driver-595
sudo reboot
```

如果 ROS 2 只是在运行 `colcon build`，技术上可以同时装，但驱动安装占用资源且最后需要重启，仍建议等构建结束。不要强行删除任何 `apt/dpkg` 锁文件。
