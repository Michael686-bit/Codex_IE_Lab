## 7. 助手

PNS 是 S1 机器人上的厂家导航/路径规划服务。

它主要负责：

- 判断起点和目标姿态是否有效；
- 根据静态 ESDF 地图进行碰撞检查；
- 检查路径途中是否存在静态障碍；
- 搜索可行路径，并返回是否可达。

调用关系可以理解为：

```text
守护 CLI
  → 通过 SDK 发起 RPC
  → PNS 查询静态 ESDF、检查碰撞并规划路径
  → 返回可达/不可达
  → CLI 决定是否提交真实导航
```

上次的结果就是 PNS 判断目标处的底盘碰撞球净空不足：

```text
球半径：    0.170 m
ESDF 距离：0.145–0.163 m
```

因此返回目标无效，守护 CLI 在底盘运动前拒绝了导航。

需要注意：现有资料尚未确认 **PNS 三个字母的官方英文全称**，所以目前应称为“厂家 PNS 导航规划服务”，不要擅自展开缩写。
