## 3. 助手

重定位子命令是 `relocalize`：

```bash
/home/galbot/ie_lab/bin/s1-python \
  /home/galbot/Lsy03/navigation_tests/s1_navigation_cli.py \
  relocalize \
  --x 1.0 \
  --y -1.0 \
  --yaw -1.0 \
  --observe 10 \
  --interval 1
```

其中 `x/y/yaw` 必须填写机器人当前真实的地图位姿，不能照抄示例。命令会要求输入类似：

```text
RELOCALIZE_MAP_1.000_-1.000_YAW_-1.000
```

它不会发送底盘、机械臂、夹爪或升降柱运动命令，但会重设地图坐标系中的定位估计。重定位结果确认正确前，不要继续执行 `relative` 或 `navigate`。
