## 1. 用户

这套代码仍然有用。现在无法展示的原因已经在日志里明确：

```text
FileNotFoundError:
SSH ControlPath does not exist:
/tmp/s1_codex_mux_20260831_lidar
```

也就是SSH复用连接已经过期或被清理。`live_lidar_ssh_bridge.py` 因此直接退出，导致：

- 三路点云没有发布；
- S1实时TF没有发布；
- `map → base_link → 左臂末端` 链不完整；
- 左末端绑定的黄色/青色框无法显示；
- RViz只剩没有实时状态的白色RobotModel。

这些惯量警告：

```text
unrealistic inertia
```

不是本次故障原因。

## 恢复步骤

先在启动RViz的终端按 `Ctrl+C`，停止当前残缺Launch。当前残留的是：

```text
Launch PID: 634077
RViz PID:   634084
```

如果找不到原终端，可在主机执行：

```bash
kill -INT 634077
```

然后重新建立SSH连接：

```bash
umask 077
ssh -fN -M \
  -S /tmp/s1_codex_mux_20260831_lidar \
  -o ControlPersist=2h \
  galbot@10.34.216.17
```

确认连接：

```bash
ssh -S /tmp/s1_codex_mux_20260831_lidar \
  -O check \
  galbot@10.34.216.17
```

应该看到类似：

```text
Master running
```

重新上传S1临时脚本，因为S1重启或 `/tmp` 清理后文件可能消失：

```bash
cd '/home/lsy03/文档/ChatGPT/S1'

scp -o ControlPath=/tmp/s1_codex_mux_20260831_lidar \
  experiments/20260831_s1_lidar_live_rviz/s1_lidar_stream.py \
  galbot@10.34.216.17:/tmp/s1_lidar_stream_20260831.py
```

再启动：

```bash
cd '/home/lsy03/文档/ChatGPT/S1/experiments/20260822_s1_rviz_demo/ros2_ws'

source /opt/ros/humble/setup.bash
source install/setup.bash

mkdir -p /tmp/s1_live_lidar_ros_logs
export ROS_LOG_DIR=/tmp/s1_live_lidar_ros_logs
export ROS_DOMAIN_ID=84

ros2 launch s1_rviz_demo view_live_lidars.launch.py
```

正常时终端会出现：

```text
Starting passive S1 LiDAR stream
first_frame ... chassis
first_frame ... head
first_frame ... back
Received LiDAR frames: chassis=..., head=..., back=...
```

注意一定要先关闭当前残缺Launch再重启，否则会再次出现两个Marker发布者，黄色/青色框又会横跳。SSH连接只保持2小时，过期后需要重新执行第一步。
