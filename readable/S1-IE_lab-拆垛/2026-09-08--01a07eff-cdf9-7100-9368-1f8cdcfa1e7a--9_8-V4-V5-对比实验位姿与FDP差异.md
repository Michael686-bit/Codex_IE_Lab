目前主输出估计的是**箱体几何中心**，即 `T_base_link_from_4317_semantic` 的平移部分。

箱口中心不是独立测量结果，而是基于“箱体直立、高度 175 mm”的先验推算：
```
箱口中心 = 箱体中心 + 87.5 mm × 高度轴
```

所以当前同时输出箱体中心、推算箱口中心、四角和短边中点，但核心估计量是箱体中心与 yaw。箱口高度和四角仍受尺寸模型是否正确影响。

关于准确率，需要区分三件事：

| 指标当前结果           |              |
| ---------------- | ------------ |
| D02–D12 目标实例人工确认 | 11/11        |
| 联合初值阶段几何门禁通过     | 4/11，约 36.4% |
| 加入内外表面一致性后的最终通过  | 0/11         |
| 绝对位姿准确率          | 暂时无法计算       |

最终 0/11 是**接受率**，不能说成“识别准确率为 0%”。算法主动拒绝了它认为不可信的结果，并没有独立真值告诉我们候选到底偏了多少。

目前没有箱体真实中心、真实 yaw 或短边接触点的测量值，因此以下指标都还算不出来：

- 中心误差多少毫米；
- yaw 误差多少度；
- 有多少帧落在抓取容差内；
- 错误接受率；
- 真正的识别准确率。

已有 FDP 差异也不能充当真值。历史 8 个样本中 ROI 与 FDP 的 XY 差平均约 19.5 mm、最大约 26.5 mm，yaw 差平均约 1.93°；这些只能说明两种算法相差多少，不能说明谁更准。

对于“随高度变化的内外壳体截面模型”，现在也不能诚实地预测一个成功率百分比。它能确定解决的是一个真实系统误差：

- 最大外形宽约 300 mm；
- 距顶 50 mm 的箱身宽度只有约 268–273 mm；
- 长向箱身截面约 370–375 mm，而非 400 mm；
- 截面还随高度变化。

因此它有希望消除当前约 25–35 mm 的尺寸模型偏差，但最终能否达到 5 mm、10 mm 或 20 mm，仍取决于深度误差、手眼标定、mask 边界和可见表面。现阶段可以把 **中心 5–10 mm、yaw 1–2°** 作为后续设计目标，而不能称为预估性能或承诺。

我不建议直接把完整 mesh 丢给普通 ICP。原因是：

- ICP 需要可靠初值；
- 箱体有内壁、外壁、法兰、筋条和重复结构；
- 错误的内外表面也可能得到很低的 ICP 残差；
- 开口箱存在 180° 对称和部分可见问题；
- 当前 D05 已出现两个 yaw 很接近、中心相差约 31 mm 的解释，ICP 很可能只会把其中一个局部解拟合得更漂亮。

更合适的是：
```css
确认 mask + 深度
        ↓
当前多平面方法给出多个 x/y/yaw/z 初值
        ↓
CAD 内外壳截面模型判断可见表面
        ↓
受约束、可见性裁剪的 point-to-plane ICP
        ↓
比较多个解并执行歧义/覆盖率门禁
```

也就是说，**ICP 应作为壳体模型后的精修和对照，不应直接替代初始化与表面识别。**

下一步我建议同时保留两条实验分支：

1. 纯壳体截面拟合，用来判断模型修正本身解决了多少问题。
2. 相同初值加可见表面 ICP，用来验证 ICP 是否真的降低残差和短边位置差，而不是增加错误接受。

之后必须增加独立参考测量，才能报告真正准确率。最直接的是给箱体与标定板建立经过测量的固定变换，或人工测量箱体中心、yaw 和两个短边参考点。

可以把 V5 理解为一条逐步增强的链路，而不是四个完全独立的识别算法：

```text
V5-0：先确认 mesh 是什么

V5-1：把 mesh 变成随高度查询的壳体模型
        ↓
V5-2：融合 B/C，生成多个有来源的初始位姿
        ↓

```

| 阶段 | 核心原理 | 当前状态 | 主要进步 |
|---|---|---|---|
| V5-0 Mesh 审计 | 检查单位、轴、原点、范围、三角面、法向、裁切接缝和表面角色 | 已完成，但 mesh 是否对应真实 4317 仍待确认 | 发现当前 OBJ 是 EU4322 的中央裁切派生模型，不是完整官方 CAD |

### V5-0：解决“模型到底是什么”

V5-0 不是位姿估计，而是资产审计。

当前确认了：

- mesh 原始轴：X=长、Y=高、Z=宽；
- 语义轴：X=长、Y=宽、Z=高；
- 最大范围约 `402.119 × 300.248 × 175 mm`；
- 顶部约为 `Y=0`，底部约为 `Y=-175 mm`；
- 文件头写明中央裁切/折叠了约 `55.003 mm`；
- 表面角色目前是启发式分类，不是厂家标签。

它回答了“这个 mesh 如何解释”，但还没有完全回答“它是否就是当前实物 4317 的官方模型”。

### V5-1：解决“每个高度应该用什么尺寸”

V5-1 把完整 mesh 预计算成轻量查找模型：

- 每 5 mm 一个高度层，共 36 层；
- 记录长向、宽向截面；
- 记录内壁、外壁、法兰、底部结构、筋条和裁切接缝；
- 缓存三角面中心、法向、面积和表面角色。

核心变化是：

```text
V4：所有侧壁都假设为 400 × 300 mm
V5-1：根据高度和表面角色查询实际截面
```

因此可以区分：

- 顶部法兰/箱口外沿；
- 箱身外壁；
- 箱身内壁；
- 底部法兰；
- 筋条或人工裁切接缝。

但这些表面角色目前仍是启发式的，不能直接当作实物真值。

### V5-2：解决“B 和 C 如何共同提供初值”

V5-2 计划做的不是把两个结果平均，而是：

- B 提供箱口、箱沿和 yaw 候选；
- C 提供侧壁方向、相对面、中心和高度区间；
- 检查二者是否属于同一组物理表面；
- 为每个候选标记来源：观测、mesh 先验或直立约束；
- 保留多个接近但物理解释不同的候选。

当前 V5-2 还没有形成正式实验结果，所以“能否生成多个可靠初值”尚未验证。

### V5-3：解决“只靠 mesh 模型本身能改善多少”

V5-3 不使用 ICP，而是：

1. 使用 V4/B/C 产生的 x/y/z/yaw 候选作为初值；
2. 根据相机可见性筛选 mesh 表面；
3. 使用 rim、outer shell、inner shell 点集；
4. 排除 central cut seam、bottom flange 和 unknown surface；
5. 用鲁棒最近点距离拟合箱体位姿。

优化变量先限制为：

```text
x / y / z / yaw
```

D02–D12 结果：

- 11 帧运行无错误；
- 9/11 通过当前几何拟合门限；
- D08 没有可用初值；
- D12 残差和覆盖率不足；
- 多数通过帧的 p90 残差约为 14–21 mm。

但 9/11 只是“模型拟合门限通过”，不是位姿准确率。所有结果仍然是：

```text
grasp_ready = false
outer_surface_identity_verified = false
accuracy_validated = false
```

### V5 相比 V4 的真正进步

V4 的核心问题是：

```text
看到任何侧壁，都用固定 400 × 300 mm 外矩形解释
```

V5 的进步是：

```text
先理解 mesh 的表面和高度变化，
再用可能对应的内壁、外壁或法兰去解释观测点。
```

具体进步有四点：

1. 从固定尺寸模型升级为高度相关模型；
2. 从“单一箱体解释”升级为内壁/外壁/法兰多种表面解释；
3. 从直接拟合升级为保留候选来源和竞争解释；
4. 在加入 ICP 前，先建立纯壳体拟合基线，单独评估 mesh 模型修正的贡献。

一句话总结：

> V5-0 解决“模型身份和几何合同”，V5-1 解决“不同高度的真实壳体尺寸”，V5-2 计划解决“B/C 如何产生多个可解释初值”，V5-3 已经验证“mesh 壳体模型本身能够明显改善局部几何拟合”，但还没有证明绝对位姿准确，也还没有进入 ICP。
