**1. 如何判断箱体位姿**

流程是：

```text
腕部 RGB-D
  → SAM3 分割出各个箱子的 mask
  → LingBot 补全深度
  → ROI 几何估计、型号/层高筛选、选定目标箱
  → RGB + 深度 + 目标 mask + 相机内参 + 箱体 mesh
  → FoundationPose++ 输出箱体 6D 位姿
  → 转换到机器人 base_link 坐标系
```

这里有两个不同层次的“位姿”：

- **ROI 粗几何**：提供箱体位置、平面朝向、尺寸和层数，用于选箱和粗接近。
- **FDP 精位姿**：输出完整的 `4×4` 矩阵，包含三维位置和旋转，供后续抓取计算。

坐标转换关系为：

\[
T_{\text{base←箱体}}
=
T_{\text{base←相机}}
\,T_{\text{相机←箱体}}
\]

相机装在腕上，因此必须使用**拍照时刻的相机变换**。

**2. 如何从箱体位姿找到抓取点**

先明确 mesh 的轴分别对应箱体长、宽、高，再选择要抓的箱沿/侧面，在箱体坐标系中定义夹爪目标。位置计算可以理解成：

\[
p_{\text{抓取}}^{base}
=
p_{\text{箱体}}^{base}
+
R_{\text{箱体}}^{base}\,d_{\text{抓取偏移}}^{箱体}
\]

其中偏移包含箱体半尺寸、抓取高度、夹爪 TCP 与接触位置之间的距离；实际实现还可能叠加人工示教修正。

随后生成：

```text
预抓位 → 接近到抓取位 → 合爪 → 提升/抽出
```

**抓取目标还包含夹爪朝向，不只是一个 XYZ 点。** 箱体旋转是否完整传给夹爪，还是经过轴向约束、固定姿态处理，要看对应模式的目标生成代码。
