## 4. 用户

ADD-S 评估误差 是什么意思？

## 5. 助手

ADD-S 是一种用于评价三维物体位姿估计准确度的指标，可理解为“考虑物体对称性的平均模型点距离”。

其计算方式大致为：

\[
ADD\text{-}S=\frac{1}{|M|}\sum_{x\in M}\min_{y\in M}
\left\|T_{gt}x-T_{pred}y\right\|
\]

其中：

- \(M\)：物体的 3D 模型点；
- \(T_{gt}\)：真实位姿；
- \(T_{pred}\)：预测位姿；
- 对每个真实模型点，寻找预测模型中距离最近的点，再求平均。

例如论文中的：

- `Mean ADD-S = 0.0106 m`
  表示预测位姿与真实位姿相比，模型点平均偏差约为 **1.06 cm**。
- `ADD-S < 2 cm = 96%`
  表示 **96% 的测试样本**平均误差小于 2 cm，并不是说所有点的最大误差都小于 2 cm。

ADD-S 特别适合瓶子、罐子等具有旋转对称性的物体：即使模型发生某些对称旋转，只要几何形状基本重合，ADD-S 仍会认为误差较小。

需要注意：ADD-S 是最终的“位姿估计误差”，不是 ICP 内部的点云配准残差。

## 7. 助手

你表里的 p50/p90/p95 和 ADD-S 使用的是同一类“最近点距离”，但统计方式不同。

设每个模型点的最近点距离为：

\[
d_i=\min_{y\in M}\|T_{gt}x_i-T_{pred}y\|
\]

那么：

\[
ADD\text{-}S=\frac{1}{N}\sum_i d_i
\]

也就是对所有模型点的最近点距离求平均。

| 指标 | 统计方式 | 含义 |
|---|---|---|
| ADD-S | 平均值 | 所有模型点的平均位姿误差 |
| p50 | 中位数 | 50% 的模型点误差不超过该值 |
| p90 | 90%分位数 | 90% 的模型点误差不超过该值 |
| p95 | 95%分位数 | 95% 的模型点误差不超过该值 |

所以你表中的：

- p50 = 8.67 mm：典型模型点误差约为 8.67 mm；
- p90 = 27.94 mm：尾部已有一部分点误差超过 27.94 mm；
- p95 = 45.78 mm：最差的约 5% 模型点误差超过 45.78 mm。

关键区别是：

- **ADD-S 是平均误差**；
- **p50/p90/p95 是误差分布的分位数**；
- 仅凭 p50、p90、p95，不能准确反推出 ADD-S，因为不知道每个区间内点的具体分布，尤其不知道最差 5% 的误差有多大。

例如，如果你的点级距离数组是 `d`：

```python
ADD_S = d.mean()
p50, p90, p95 = np.percentile(d, [50, 90, 95])
```

因此，你的表可以理解为“ADD-S 点级误差分布”，而论文中的 `Mean ADD-S = 10.6 mm` 是把这些点的距离求平均后的结果；如果论文还对多帧数据取平均，则它是“每帧 ADD-S 再跨帧平均”。它不是 p50、p90 或 p95。

## 16. 用户

如果我需要 计算  ADD-S 是否我应该使用我拿尺子在现场真实测量到的数值？而不是使用FDP的数据来进行对比？

## 17. 助手

是的。若要计算“绝对 ADD-S 位姿误差”，应使用独立的现场真实测量结果作为 \(T_{gt}\)，而不是 FDP 输出。

\[
ADD\text{-}S=
\frac{1}{N}\sum_i
\min_j\left\|T_{gt}x_i-T_{pred}x_j\right\|
\]

其中：

- \(T_{gt}\)：尺子、标记板、运动捕捉或测量设备得到的真实位姿；
- \(T_{pred}\)：ICP 输出位姿；
- \(x_i\)：同一个物体 mesh 上的模型点。

需要注意，尺子测量必须足以构造完整位姿：

- 如果只测了中心 XYZ，可以计算中心位置误差，但不能计算完整 ADD-S；
- 如果测得中心 XYZ + yaw，且确认 roll/pitch 为零，可以计算当前 4DoF 版本的 ADD-S；
- 如果物体存在倾斜，还需要测量 roll/pitch；
- 更可靠的方式是测量箱体上 3 个以上不共线的角点/特征点，再拟合完整 6D 刚体位姿。

FDP 可以继续使用，但只能作为：

```text
ADD-S_vs_FDP
```

表示“ICP 与 FDP 的差异”，不能称为真实误差或准确率。

另外必须确认现场实物与 `model.obj` 是同一个几何模型。若 mesh 尺寸、原点或轴方向不一致，ADD-S 会同时包含“位姿误差”和“模型误差”。

对当前项目，推荐：

1. 用尺子或标记点独立测出箱体真实位姿；
2. 将真实位姿和 ICP 输出统一到同一 `base_link` 或 camera 坐标系；
3. 用同一个确认过的 mesh 计算 ADD-S；
4. 同时报告测量不确定度，例如 `ADD-S = 8.5 mm ± 3 mm`；
5. 另行报告 ICP 的 point-to-plane RMSE，不能混为 ADD-S。

| YCB-Video 实验 | 直接使用数据集已有的 6D 位姿标注 |

因此论文中 crate 实验的：

\[
\text{Mean ADD-S}=0.0106\text{ m}
\]

是相对于**仿真器生成的真实位姿**计算的，不是现场尺子测量值。[论文原文第 5.1 节](https://publications.ri.cmu.edu/storage/publications/2020/06/msr_thesis_adityaa2.pdf)

1. 第一帧人工估计；
2. 后续帧用 ICP 自动传播；
3. 再拿这些 ICP 生成的标注评价其它算法。

所以它可能存在一定的 ICP 方法偏置，不能等同于高精度测量系统。

论文在 RoMan 机器人上的真实 crate 场景主要是定性展示，没有给出像仿真实验那样可靠的绝对 ADD-S 数值。

对我们现在的 S1，最实际的办法不一定是拿尺子测每一帧，而是：

- 用固定底板、两个垂直挡块约束箱体位置和 yaw；
- 用 AprilTag/ArUco 标记获取箱体参考位姿；
- 或用测量好的治具定义箱体的已知位姿。

然后得到 \(T_{gt}\)，再和 ICP 的 \(T_{pred}\) 计算 ADD-S。FDP 可以作为对照，但不应作为 ground truth。

## 22. 助手

你的理解基本正确，但第二句需要稍微修正。

当前表格中的 p50/p90/p95 是：

\[
d_i^{fit}=\min_{q\in Q_{obs}}
\left\|T_{pred}m_i-q\right\|
\]

其中：

- \(m_i\)：箱体 mesh 上的模型点；
- \(T_{pred}\)：ICP 拟合得到的位姿；
- \(Q_{obs}\)：实际采集到的箱体点云。

所以它们表示：

> ICP 拟合后的 mesh 与实际观测点云之间的几何贴合程度。

例如 p90 = 27.94 mm，表示约 90% 的被选模型点，在观测点云中能找到 27.94 mm 以内的最近点。当前实现中通常只统计可见、筛选后的壳体模型点，并不是完整 mesh。

而标准 ADD-S 是：

\[
d_i^{ADD-S}=\min_{m_j\in M}
\left\|T_{gt}m_i-T_{pred}m_j\right\|
\]

\[
ADD\text{-}S=\frac{1}{N}\sum_i d_i^{ADD-S}
\]

它比较的是：

> 同一个 mesh 在真实位姿 \(T_{gt}\) 下的位置，与在预测位姿 \(T_{pred}\) 下的位置之间的误差。

这里的“真实点”严格来说不是实际传感器采集到的点，而是：

```text
同一个模型 mesh
    ├── 用真实位姿变换 → 真实模型点
    └── 用预测位姿变换 → 预测模型点
```

两组模型点之间做最近点距离。

| 指标 | 对比对象 | 是否需要真实位姿 |
|---|---|---|
| p50/p90/p95 | 预测 mesh ↔ 实际观测点云 | 不需要 |
| ICP point-to-plane RMSE | 预测 mesh ↔ 观测点云的点面残差 | 不需要 |
| ADD-S | 真实位姿 mesh ↔ 预测位姿 mesh | 需要 |

因此：

- 你的 p50/p90/p95 是“拟合质量/配准残差”；
- ADD-S 是“相对于真实位姿的估计误差”；
- 两者单位都可以是 mm，但不能直接互相替代；
- p90 很小，也不能保证 ADD-S 很小，因为可能拟合到了错误的内壁、法兰或遮挡区域。

当前项目中的 p 值确实来自 [constrained_icp.py](/home/lsy03/文档/ChatGPT/S1/experiments/20260907_bin_rim_pose/constrained_icp.py:141) 里的模型到观测点云距离。

|---|---|
| 和论文比较 | ADD-S、Mean ADD-S、ADD-S 小于 2 cm 的比例 |
| 判断 ICP 是否收敛 | point-to-plane RMSE、模型→观测 p90 |
| 判断是否存在离群点/遮挡 | p95、内点率、覆盖率 |
| 判断抓取是否可靠 | 箱体中心误差、yaw 误差、两条短边抓取点误差 |
| 没有真实位姿时 | 只能做拟合质量和后端间一致性，不能证明绝对准确率 |

对你当前项目，建议优先级是：

1. 独立测量得到真实位姿后，计算箱体中心、yaw、抓取点误差；
2. 使用同一个 mesh 计算 ADD-S；
3. 在线 ICP 判断使用模型→观测 p90 + point-to-plane RMSE + 内点率/覆盖率；
4. 同时检查内壁/外壁竞争解和 0°/180° 对称解差距。

不要只看 p50，因为 p50 只反映一半模型点，可能掩盖严重的局部错误。也不要只看 RMSE，因为错误表面或退化平面上也可能得到较小 RMSE。

对于你现有 D/H 数据：

- `p90`、`point-to-plane RMSE`：可以作为 ICP 配准质量指标；
- `ADD-S_vs_FDP`：只能表示和 FDP 的一致性；
- 没有独立真值时，暂时不能说哪个算法的绝对位姿误差更小。
