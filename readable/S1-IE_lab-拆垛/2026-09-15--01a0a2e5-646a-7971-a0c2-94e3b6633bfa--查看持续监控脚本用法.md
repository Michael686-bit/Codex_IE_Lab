## 怎么启动

你现在就在 `deploy` 目录，使用：

```bash
bash start_continuous_monitored.sh --execute
```

默认自动生成任务名，例如 `random_20260915_143000`。也可以指定名字：

```bash
bash start_continuous_monitored.sh --execute test_20260915_01
```

**任务名必须是新的**，已有运行目录或监控目录就会拒绝，不会自动续跑。用 `bash` 启动不需要加执行权限。

## 启动后做什么

它会同时运行：

| 部分 | 行为 |
|---|---|
| 连续拆垛任务 | 预检查 → SAM 姿态准备与导航 → 自主观察、抓取、卸箱 |
| 夹爪记录监控 | 每 2 秒读取任务已有文件，保存夹爪等记录 |
| 中心偏差汇总 | 每 5 秒更新统计，退出时再汇总一次 |

实际入口是 `run.sh dev-run`，使用 `continuous_validation.yaml`，并传入 **`--execute --yes`**：会执行真机任务，不应期待每一步再弹人工确认；机器校验仍保留。

**运行涉及 S1 机械臂、夹爪和底盘，升降动作及具体速度需进一步核对任务配置。** 启动前需确认运动区域无人员和障碍、卸箱区持续净空、物理急停可用；这份包装脚本本身不设置速度。

## 日志在哪

```text
/home/galbot/ie_lab/data/s1_continuous_destack/
├── runs/<任务名>/                    # 主任务数据
└── monitoring/<任务名>/
    ├── mission.log                  # 主任务终端日志
    ├── grippers.jsonl               # 夹爪等文件观测记录
    ├── grippers.stderr.log
    └── centers/
        ├── centers.json
        └── centers.csv
```

终端也会实时显示主任务日志。两个监控器只是读取文件，**不是独立的实时安全监控或急停机制**。

## 怎么停

在启动终端按 **Ctrl+C** 请求中断。包装脚本会清理两个监控进程，底层启动器有控制器停止与清理逻辑；**不能仅凭终端退出判断机器人已安全停稳**。出现危险时使用物理急停。
