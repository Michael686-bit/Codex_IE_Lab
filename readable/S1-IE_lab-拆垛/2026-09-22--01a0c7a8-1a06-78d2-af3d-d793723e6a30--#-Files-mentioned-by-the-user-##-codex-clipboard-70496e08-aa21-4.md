这是“从当前消息创建聊天分支”：保留到这条消息为止的对话，另开一个聊天，方便尝试不同方案。

两个选项的区别在于**是否共用代码文件**：

|选项|含义|适合场景|
|---|---|---|
|在此工作树中创建分支|新聊天和原聊天操作同一份项目文件，一边修改，另一边也会看到|继续分析同一份数据、讨论不同问题|
|在新工作树中创建分支|新聊天使用单独的 Git 工作目录，方便隔离代码修改|尝试新算法、修改程序，同时保留原来的实现|

这里的“聊天分支”与“Git 分支”是两个概念；“工作树”可以理解为一份可独立编辑的项目目录。

针对我们这个实验：**只分析已有结果，选“在此工作树”；要尝试修改算法或门禁，选“在新工作树”。** 新工作树中的大型数据、未跟踪文件和运行环境是否齐全，需要另外检查。
