## 4. 助手

找到了，你记得的**左右腕相机采集脚本**是这两个：

- 左腕：[capture_left_wrist_rgbd_once.py](/home/lsy03/文档/ChatGPT/S1/experiments/20260903_fdp_baseline/scripts/capture_left_wrist_rgbd_once.py)
- 右腕：[capture_right_wrist_rgbd_once.py](/home/lsy03/文档/ChatGPT/S1/experiments/20260903_fdp_baseline/scripts/capture_right_wrist_rgbd_once.py)

它们**每次采一侧的一帧**，保存 RGB、原始深度、相机内参 K、采集时刻相机到基座的 TF 和状态元数据。只读采集，不会移动手臂、夹爪、升降或底盘。

按历史部署，在 **S1 Orin 的终端**执行：

```bash
cd /home/galbot/Lsy03/fdp_baseline

# 左腕
/home/galbot/ie_lab/bin/s1-python scripts/capture_left_wrist_rgbd_once.py \
  --output-dir "captures/left_contents_$(date +%Y%m%d_%H%M%S)" \
  --acknowledge-readonly-live-s1

# 右腕
/home/galbot/ie_lab/bin/s1-python scripts/capture_right_wrist_rgbd_once.py \
  --output-dir "captures/right_contents_$(date +%Y%m%d_%H%M%S)" \
  --acknowledge-readonly-live-s1
```

当前远端文件是否仍在，我这次没有 SSH 核查。完整说明在[左右腕采集指南](../../assets/bbb4a3fed64f0d32--WRIST_CAPTURE_GUIDE_20260909.md)。

对于“箱里放东西后识别不准”，建议固定箱子和相机位置，采**空箱／有物品**两组，再对比目标 mask、深度和 FDP 位姿，先验证这个猜测。

另外，若你指的是后来 **67 帧的 `interactive_rgbd_capture` 交互采集工具**，那是另一套；历史记录保留了数据，但当时没找到对应采集源码。
