## 4. 助手

**有，仓库里已经有六路实时查看器，曾于 2026-09-17 在 S1 上短时实测成功。**

| 位置 | 可显示数据 |
|---|---|
| 头部左、右摄像头 | 两路 RGB |
| 左腕摄像头 | RGB + 原生深度 |
| 右腕摄像头 | RGB + 原生深度 |

默认 **3 列 × 2 行同屏显示**，支持点击单路放大、滚轮缩放，鼠标移到深度图可查看对应像素的**米制深度值**，并显示各路在线、帧率和停更状态。头部深度尚未接入。

在本机图形桌面终端运行：

```bash
cd '/home/lsy03/文档/ChatGPT/S1/experiments/20260916_s1_camera_viewer/ros2_ws'
source /opt/ros/humble/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=84
export ROS_LOCALHOST_ONLY=1
export ROS_LOG_DIR=/tmp/s1_camera_viewer_core_rgbd_logs

ros2 launch s1_camera_viewer live_core_rgbd_viewer.launch.py \
  rate_hz:=1.0 duration_s:=0.0 headless:=false
```

该命令会通过 SSH 连接 S1 并持续读取相机，预期不会驱动头部、手臂、夹爪、升降或底盘运动；按 `Ctrl+C` 停止。目前验证的是低频短时运行，长期稳定性和与 Mode 00 并行的负载影响仍待验证。
