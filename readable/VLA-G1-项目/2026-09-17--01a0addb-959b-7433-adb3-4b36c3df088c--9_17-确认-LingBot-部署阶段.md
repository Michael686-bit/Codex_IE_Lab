如果安装仿真，需要单独建立 RoboTwin 环境，不能混进现有 LingBot Docker。官方环境要求 Linux、NVIDIA GPU、Python 3.10、Vulkan，CUDA 12.1 是推荐版本。 citeturn3view0

大致流程是：

```bash
git clone --recurse-submodules https://github.com/RoboTwin-Platform/RoboTwin.git
cd RoboTwin

conda create -n RoboTwin python=3.10 -y
conda activate RoboTwin

bash scripts/_install.sh
bash scripts/_download_assets.sh
```

然后让 RoboTwin 作为“可视化仿真器”，让当前 LingBot 服务作为“策略服务器”，通过 WebSocket 连接。这样可以看到机器人执行任务，同时完全不接触 G1 真机。

建议顺序：

1. 先看官方 RoboTwin 演示；
2. 安装 RoboTwin 并打开一个空场景；
3. 运行一个简单任务；
4. 接入 LingBot；
5. 最后才考虑 G1 映射。

当前 RTX 4090 可以尝试这条路线，但模型和仿真共享一张 GPU，第一次建议只跑单任务、低并发。
