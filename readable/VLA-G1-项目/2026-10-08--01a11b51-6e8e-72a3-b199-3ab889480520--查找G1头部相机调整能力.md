## 5. 助手

查到的结论：可以调整，但调整的是“头部姿态带动相机改变视野”，不是相机本体独立转动。

- G1 头部有 2 个自由度：`head_joint1`、`head_joint2`，官方说明其典型用途就是“注视/相机朝向控制”。
- SDK 可通过 `set_joint_positions()` 或 `set_joint_commands()` 控制 `head` 关节组，角度单位为弧度。
- 头部左右相机通常会随头部一起改变方向；文档没有提供单独调整某一个镜头的云台、变焦或对焦接口。
- 当前资料没有明确说明两个关节分别对应水平/俯仰，也没有给出 G1 的具体关节限位，因此不要直接套用其他型号的限位值。

示例：

```python
robot.set_joint_positions(
    [0.2, 0.2],       # 两个头部关节角度，示例值，单位 rad
    joint_groups=["head"],
    is_blocking=True,
    speed_rad_s=0.1,
    timeout_s=10.0,
)
```

官方参考：[G1 Python API](https://developer.galbot.com/docs/SDK/1.9.1/g1/zh/api_python_reference/) 、[G1 Python 示例](https://developer.galbot.com/docs/SDK/1.9.1/g1/zh/examples_python/)。

```bash
import time
from galbot_sdk.g1 import GalbotRobot, ControlStatus

target = 0.45
joint = "head_joint2"
robot = GalbotRobot()
initialized = False

try:
    initialized = bool(robot.init())
    if not initialized or not robot.is_running():
        raise RuntimeError("G1 SDK 初始化失败")

    time.sleep(2)
    state = list(robot.get_joint_states([], [joint]))
    controller = str(robot.get_active_controller("head"))

    print(f"当前 {joint}: {state[0].position:.6f} rad")
    print(f"头部控制器: {controller}")

    if controller != "head_pvt_ctrl":
        raise RuntimeError(f"头部控制器异常: {controller}")
    if abs(float(state[0].velocity)) > 0.002:
        raise RuntimeError("头部当前正在运动，已中止")
    if not (-0.2143461 <= target <= 0.4935988):
        raise RuntimeError("目标超出 head_joint2 限位")

    print("注意：0.45 rad 已接近上限，开始缓速执行……")
    status = robot.set_joint_positions(
        [target], [], [joint], True, 0.03, 30.0
    )
    print(f"ControlStatus: {status}")

    if status != ControlStatus.SUCCESS:
        raise RuntimeError("运动命令失败")

finally:
    if initialized:
        robot.request_shutdown()
        robot.wait_for_shutdown()
        robot.destroy()
PY
```
