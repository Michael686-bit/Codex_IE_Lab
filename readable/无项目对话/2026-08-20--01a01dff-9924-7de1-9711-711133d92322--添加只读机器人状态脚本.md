"""
实验 01：只读状态获取（read-only robot state）

目标：
- 初始化 Galbot SDK（GalbotRobot，MachineType.S1）
- 读取设备信息 / 关节组 / 关节状态 / IMU（均为只读）
- 不产生任何运动命令

安全说明：
- 本脚本不发送任何运动指令（set_* / execute_* / publish_* 均不使用）
- 运行前提：机器人已上电、急停已释放、SDK 环境已配置（source setup.sh / 环境变量）
- 运行位置：机器人本体或可访问机器人网络并已安装 galbot_sdk 的机器
- 若初始化失败，检查机器人连接与 SDK 环境，不要继续

运行方式：
    python3 read_robot_state.py [--group left_arm,right_arm]

参考：
    third_party/GalbotSDK/docs/s1/zh/python/galbot_robot/get_joint_states.py
    third_party/GalbotSDK/docs/s1/zh/python/galbot_robot/get_device_information.py
"""

import argparse
import sys
import time

from galbot_sdk.s1 import GalbotRobot


def print_joint_states(joint_states):
    for js in joint_states:
        print(f"    position={js.position:.4f}  velocity={js.velocity:.4f}  "
              f"acceleration={js.acceleration:.4f}  effort={js.effort:.4f}  current={js.current:.4f}")


def main():
    parser = argparse.ArgumentParser(description="Read-only Galbot S1 state query")
    parser.add_argument("--group", default="left_arm,right_arm",
                        help="comma separated joint group names, e.g. left_arm,right_arm,torso,head")
    args = parser.parse_args()
    groups = [g.strip() for g in args.group.split(",") if g.strip()]

    robot = GalbotRobot()

    state = robot.init()
    if not state:
        print("初始化失败：请检查机器人连接与 SDK 环境")
        sys.exit(1)
    print("初始化成功")

    time.sleep(1)

    print("\n=== 设备信息 ===")
    info = robot.get_device_information()
    for k, v in info.items():
        print(f"    {k}: {v}")

    print("\n=== 关节组 ===")
    all_groups = robot.get_joint_group_names()
    print(f"    {all_groups}")

    print("\n=== 关节状态 ===")
    for g in groups:
        print(f"[{g}]")
        try:
            states = robot.get_joint_states([g], [])
            print_joint_states(states)
        except Exception as e:
            print(f"    get_joint_states({g}) 失败: {e}")

    print("\n=== IMU ===")
    try:
        from galbot_sdk.s1 import SensorType
        imu = robot.get_imu_data(SensorType.HEAD_IMU)
        print(f"    {imu}")
    except Exception as e:
        print(f"    get_imu_data 失败: {e}")

    robot.request_shutdown()
    robot.wait_for_shutdown()
    robot.destroy()
    print("\n资源已释放，退出")


if __name__ == "__main__":
    main()

## 2. 助手

这段脚本用于**只读获取 Galbot S1 机器人的状态信息**，包括设备信息、关节组、关节状态和头部 IMU 数据。它不会调用任何运动控制接口。

### 1. 导入依赖

```python
import argparse
import sys
import time

from galbot_sdk.s1 import GalbotRobot
```

- `argparse`：解析命令行参数。
- `sys`：初始化失败时通过 `sys.exit(1)` 退出。
- `time`：初始化成功后等待 1 秒。
- `GalbotRobot`：Galbot S1 SDK 的机器人主接口。

注释中提到 `MachineType.S1`，但当前代码没有显式传入 `MachineType.S1`，而是直接使用了 S1 模块下的 `GalbotRobot()`。

### 2. 打印关节状态

```python
def print_joint_states(joint_states):
    for js in joint_states:
        print(...)
```

函数遍历 SDK 返回的每个关节状态，打印：

- `position`：关节位置，通常是角度或位移。
- `velocity`：关节速度。
- `acceleration`：关节加速度。
- `effort`：关节输出力或力矩。
- `current`：电机电流。

`.4f` 表示保留 4 位小数。

这里没有打印关节名称，因此输出值依赖 SDK 返回顺序。若需要把数值与具体关节对应起来，应同时获取或打印关节名。

### 4. 创建并初始化机器人对象

```python
robot = GalbotRobot()
state = robot.init()
```

- `GalbotRobot()` 创建 SDK 接口对象。
- `robot.init()` 建立 SDK 所需的通信和运行环境。

如果初始化失败：

```python
if not state:
    print("初始化失败：请检查机器人连接与 SDK 环境")
    sys.exit(1)
```

程序立即退出，不继续访问设备。这符合脚本开头的安全说明。

不过，`if not state` 是否正确取决于 SDK 的返回类型。如果 `init()` 返回的是状态枚举或状态对象，而不是布尔值，就应按照 SDK 文档判断成功状态。

初始化成功后：

```python
time.sleep(1)
```

等待一秒，让通信和状态数据流稳定。这不是运动命令。

```python
info = robot.get_device_information()

```

这里假设返回值是字典，逐项输出设备信息，例如型号、序列号或软件版本等。具体字段由 SDK 和设备版本决定。

### 6. 获取所有关节组

```python
all_groups = robot.get_joint_group_names()
print(f"    {all_groups}")
```

用于查看当前机器人支持哪些关节组。随后脚本仍然按照 `--group` 参数读取指定组。

目前没有提前检查指定名称是否存在，因此名称写错时，会在下一步捕获并打印异常。

### 7. 获取关节状态

```python
for g in groups:
    try:
        states = robot.get_joint_states([g], [])
        print_joint_states(states)
    except Exception as e:
        print(f"    get_joint_states({g}) 失败: {e}")
```

脚本逐组查询状态：

```python
robot.get_joint_states([g], [])
```

两个参数通常可理解为：

- `[g]`：需要查询的关节组列表。
- `[]`：单独指定的关节名称列表；这里为空。

例如查询左臂时实际传入：

```python
robot.get_joint_states(["left_arm"], [])
```

每个组都单独使用 `try/except`。因此某个组不存在或读取失败时，其他组仍可继续读取。

### 8. 获取 IMU 数据

```python
from galbot_sdk.s1 import SensorType
imu = robot.get_imu_data(SensorType.HEAD_IMU)
```

这会读取头部 IMU。IMU 数据通常包括：

- 加速度；
- 角速度；
- 姿态或四元数。

具体内容取决于 `imu` 对象的字段定义。当前代码直接打印对象：

```python
print(f"    {imu}")
```

如果 SDK 没有提供友好的字符串表示，输出可能不够直观，可以改为逐字段打印。

将 `SensorType` 放在 `try` 中导入的好处是：如果当前 SDK 版本不存在该类型，脚本会报告错误，而不是在程序启动时直接崩溃。

### 9. 释放 SDK 资源

```python
robot.request_shutdown()
robot.wait_for_shutdown()
robot.destroy()
```

这三步大致表示：

1. 请求 SDK 停止运行；
2. 等待停止完成；
3. 销毁对象并释放通信、线程等资源。

它们是 SDK 生命周期管理操作，不是机器人运动命令。

### 安全性结论

从代码表面看，它只调用了：

- 初始化接口；
- `get_*` 查询接口；
- 关闭和资源释放接口。

没有使用 `set_*`、`execute_*` 或 `publish_*`，因此不会主动下发运动指令。

有一个值得改进的地方：如果设备信息读取等操作抛出未捕获异常，末尾的资源释放代码不会执行。更稳妥的结构是使用 `try/finally`：

```python
robot = GalbotRobot()
try:
    state = robot.init()
    if not state:
        raise RuntimeError("初始化失败")

    # 所有只读查询
finally:
    robot.request_shutdown()
    robot.wait_for_shutdown()
    robot.destroy()
```

这样即使读取过程中发生异常，也会尽量释放 SDK 资源。
