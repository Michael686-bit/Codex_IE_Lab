## 1. 用户

是否能查看到codex额度使用情况的时间趋势？

## 2. 助手（进展）

我会查一下 Codex 当前官方支持的用量/额度查看入口，重点确认是否有“按时间趋势”的图表，以及个人版和组织版是否不同。

## 3. 助手

可以，但取决于 Codex 的计费方式：

- **使用 ChatGPT 套餐额度的 Codex**：目前通常只能看到当前额度剩余比例和重置时间；Codex App/CLI 没有提供完整的历史用量趋势图。因此不能直接查看“过去每天消耗多少额度”的曲线。
- **使用 OpenAI API Key 的 Codex**：可以在 [OpenAI Usage Dashboard](https://platform.openai.com/usage) 按日期、项目、用户和模型查看用量与费用趋势。组织管理员还可以通过 [Usage API](https://platform.openai.com/docs/api-reference/usage/moderations_object) 获取按分钟、小时或天聚合的数据，自行绘图。
- **团队/企业账户**：管理员可能拥有比普通成员更详细的组织级统计，但具体可见内容取决于工作区权限。

简而言之：**订阅制 Codex 只能看当前额度状态，API 用量则能看完整的时间趋势。**
