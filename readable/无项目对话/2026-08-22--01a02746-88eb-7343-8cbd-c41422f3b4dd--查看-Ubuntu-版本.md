## 2. 助手

可以在终端依次运行：

```bash
# 查看当前终端正在使用的 ROS 发行版
echo $ROS_DISTRO

# 查看 ROS 版本：1 或 2
echo $ROS_VERSION
```

常见输出示例：

```text
noetic
1
```

表示 **ROS 1 Noetic**；如果输出：

```text
humble
2
```

表示 **ROS 2 Humble**。

也可以检查已安装的版本：

```bash
# Ubuntu/Debian：查看所有已安装的 ROS 软件包
dpkg -l | grep '^ii  ros-'

# 查看 /opt/ros 下安装了哪些发行版
ls /opt/ros
```

如果 `echo $ROS_DISTRO` 没有输出，但 `/opt/ros` 下面存在版本目录，通常只是当前终端还没有加载 ROS 环境。比如：

```bash
source /opt/ros/humble/setup.bash
echo $ROS_DISTRO
```

进一步验证 ROS 命令是否可用：

```bash
# ROS 1
rosversion -d

# ROS 2
ros2 --help
```

最直接、可靠的组合是：

```bash
ls /opt/ros
echo "ROS_VERSION=$ROS_VERSION"
echo "ROS_DISTRO=$ROS_DISTRO"
```

## 4. 助手

从结果来看，这台电脑目前**没有通过 Ubuntu/Debian 标准方式安装 ROS**：

- `ROS_DISTRO` 和 `ROS_VERSION` 均为空：当前终端没有加载 ROS 环境。
- `dpkg -l | grep '^ii  ros-'` 无输出：未发现通过 APT 安装的 ROS 软件包。
- `/opt/ros` 不存在：ROS 1/ROS 2 的标准安装目录不存在。
- `setup.bash` 不存在：因此无法加载 ROS 2 Humble。

还可以检查是否通过源码、Snap 或 Conda 安装过：

```bash
command -v ros2
command -v roscore
find ~/ -maxdepth 4 -type f -name setup.bash 2>/dev/null
snap list | grep -i ros
conda list 2>/dev/null | grep -i ros
```

如果这些命令也没有输出，基本可以确认**尚未安装 ROS**。

安装前先查看 Ubuntu 版本：

```bash
lsb_release -a
uname -m
```

ROS 版本需要与 Ubuntu 匹配，例如：

- Ubuntu 20.04 → ROS 1 Noetic 或 ROS 2 Foxy（均已结束官方支持）
- Ubuntu 22.04 → ROS 2 Humble
- Ubuntu 24.04 → ROS 2 Jazzy
