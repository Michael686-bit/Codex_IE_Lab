## 3. 助手

Ubuntu 22.04 推荐安装 **CloudCompare 2.13.2（Flatpak 版）**。它比 Ubuntu 软件源里的 **2.11.3** 更新，也是 CloudCompare 官方为 Linux 推荐的安装方式。[官方安装说明](https://github.com/CloudCompare/CloudCompare)、[Flathub 页面](https://flathub.org/apps/org.cloudcompare.CloudCompare)

直接执行：

```bash
sudo apt update
sudo apt install -y flatpak

flatpak remote-add --if-not-exists flathub \
  https://flathub.org/repo/flathub.flatpakrepo

flatpak install -y flathub org.cloudcompare.CloudCompare
```

启动：

```bash
flatpak run org.cloudcompare.CloudCompare
```

查看版本：

```bash
flatpak run org.cloudcompare.CloudCompare --version
```

以后升级：

```bash
flatpak update org.cloudcompare.CloudCompare
```

如果只想通过 Ubuntu 的 `apt` 安装，命令是：

```bash
sudo add-apt-repository universe
sudo apt update
sudo apt install -y cloudcompare
```

但 Ubuntu 22.04 官方仓库提供的是较老的 **2.11.3**，[Ubuntu 软件包页面](https://packages.ubuntu.com/jammy/graphics/cloudcompare)，因此优先建议使用 Flatpak。注意 Flathub 的 CloudCompare目前仅提供 `x86_64` 架构；普通 Intel/AMD 64 位电脑适用。

## 5. 助手（进展）

这不是版本不兼容，而是下载 KDE 运行库时 TLS 连接被重置；已经下载的部分通常会保留，可以续传。我核对一下当前可用的恢复命令和镜像方案。

## 6. 助手

这是网络连接被重置，不是 CloudCompare 或 Ubuntu 版本问题。已下载内容会保留，先直接重试：

```bash
flatpak install -y flathub org.cloudcompare.CloudCompare
```

如果仍然失败，建议切换到国内镜像：

```bash
sudo flatpak remote-modify flathub \
  --url=https://mirror.sjtu.edu.cn/flathub

flatpak update --appstream
flatpak install -y flathub org.cloudcompare.CloudCompare
```

安装完成后启动：

```bash
flatpak run org.cloudcompare.CloudCompare
```

如果提示仓库数据损坏，再执行修复后重装：

```bash
sudo flatpak repair
flatpak install -y flathub org.cloudcompare.CloudCompare
```

查看当前软件源：

```bash
flatpak remotes --columns=name,url
```

以后需要恢复官方 Flathub 源：

```bash
sudo flatpak remote-modify flathub \
  --url=https://dl.flathub.org/repo
```

国内网络访问 Flathub 时发生 TLS 重置很常见，上海交大镜像通常会稳定很多。[SJTUG Flathub 镜像](https://mirrors.sjtug.sjtu.edu.cn/flathub/)

## 8. 助手

是的，**已经下载并安装完成**。关键提示是：

```text
Installation complete.
```

现在启动 CloudCompare：

```bash
flatpak run org.cloudcompare.CloudCompare
```

检查安装状态：

```bash
flatpak list | grep -i cloudcompare
```

终端中的两个提示不影响使用：

- `XDG_DATA_DIRS`：注销并重新登录后，CloudCompare 图标通常会出现在应用菜单中。
- KDE Platform `end-of-life`：这是 CloudCompare 当前 Flatpak 包依赖的运行库版本提示，不代表安装失败。应用仍然可以正常运行。
