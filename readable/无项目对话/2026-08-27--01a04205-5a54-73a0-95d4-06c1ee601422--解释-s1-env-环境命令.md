## 2. 助手

这条命令：

```bash
source /home/galbot/ie_lab/bin/s1-env
```

意思是：**在当前终端中加载 `s1-env` 脚本，配置机器人项目所需的运行环境。**

拆开来看：

- `source`：让当前 Shell 直接执行脚本，而不是启动一个新的子进程。
- `/home/galbot/ie_lab/bin/s1-env`：要加载的环境配置脚本路径。
- 执行后，脚本通常会设置 `PATH`、`PYTHONPATH`、动态库路径等环境变量，使普通的 `python` 能找到该项目的 Python 包、依赖库和工具。

所以：

```bash
source /home/galbot/ie_lab/bin/s1-env
python your_example.py
```

可以理解为先“进入/激活 S1 运行环境”，再运行程序。这个环境通常只对**当前终端会话**有效；关闭终端后，下次需要重新执行。

如果不想先激活环境，可以直接用封装好的解释器：

```bash
s1-python your_example.py
```

它通常相当于为这一次运行自动配置环境，然后调用正确的 Python。

你也可以执行：

```bash
type source
file /home/galbot/ie_lab/bin/s1-env
sed -n '1,200p' /home/galbot/ie_lab/bin/s1-env
```

查看 `source` 是什么，以及该脚本具体设置了哪些内容。注意，`source` 与直接执行脚本不同：

```bash
/home/galbot/ie_lab/bin/s1-env
```

后者如果在子进程中运行，其环境变量修改通常不会保留在当前终端里。
