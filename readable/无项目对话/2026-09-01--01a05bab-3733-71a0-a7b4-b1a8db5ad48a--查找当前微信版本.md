## 5. 助手

打开终端，运行：

```bash
cd ~/Downloads
sudo apt install ./WeChat*.deb
```

如果文件在中文“下载”目录：

```bash
cd ~/下载
sudo apt install ./WeChat*.deb
```

输入密码时屏幕不会显示字符，输完按回车即可。安装完成后可在应用菜单中打开微信。
