## 6. 助手

可以修改 Codex 使用的“窗口配置”，但不能突破模型自身的硬上限。GPT‑5.6 Sol 的硬上限仍是 **1,050,000 tokens**。

在用户级配置文件 `~/.codex/config.toml` 中设置：

```toml
model = "gpt-5.6-sol"

# Codex 按多少 token 作为可用上下文窗口
model_context_window = 1050000

# 达到此数量后自动压缩历史；建议预留输出和工具调用空间
model_auto_compact_token_limit = 900000

# 统计整个活动上下文
model_auto_compact_token_limit_scope = "total"
```

也可以只对某个项目设置，在项目目录创建：

```text
.codex/config.toml
```

关键区别：

- `model_context_window`：告诉 Codex 可用窗口是多少。可以调低，但设成超过模型硬上限并不会真的扩容，反而可能导致请求失败。
- `model_auto_compact_token_limit`：控制何时压缩较早的对话；如果你只是想让任务保留更多原始上下文，通常应该调整这个值。
- 想超过 **105 万 tokens**，只能换用上下文窗口更大的模型或自定义模型提供商，不能靠填写更大的数字实现。

修改后建议新建任务或重启 Codex，使配置稳定生效。配置项见 [OpenAI Codex 配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)。
