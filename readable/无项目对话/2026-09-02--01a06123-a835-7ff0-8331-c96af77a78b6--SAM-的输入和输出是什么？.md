## 1. 用户

SAM 的输入和输出是什么？

## 2. 助手

如果你指的是 Meta 的 **SAM（Segment Anything Model）**：

- **输入**
  - 一张图像
  - 可选的分割提示：前景/背景点、边界框、已有掩码；也可以自动扫描整张图

- **输出**
  - 一个或多个候选分割掩码（mask）
  - 每个掩码的质量/置信度评分
  - 低分辨率掩码 logits，可用于继续迭代提示

简化表示：

`图像 + 点/框/掩码提示 → 目标区域的分割掩码`

原始 SAM **不直接输出类别名称**，只回答“哪些像素属于同一个目标”。如果你指的是状态空间模型、软件资产管理等其他 SAM，请告诉我具体语境。

## 5. 助手

如果你说的是 Meta 的 **SAM 3（Segment Anything Model 3）**，可以概括为：

> **输入：图像/视频 + 提示（Prompt）**
> **输出：符合提示的目标掩码、位置、置信度；视频还包含跨帧目标身份。**

### 输入

1. **视觉数据**
   - 单张图像
   - 视频帧序列

2. **提示信息**
   - 文本概念：如“黄色校车”“穿白衣服的球员”
   - 边界框：正框或负框
   - 点、掩码或参考目标等视觉提示
   - 文本与视觉提示可以组合使用

从模型接口看，主要输入包括：

```text
pixel_values        图像张量 [B, 3, H, W]
input_ids           文本提示的 token
attention_mask      文本有效位置
input_boxes         提示框 [B, N, 4]
input_boxes_labels  正框/负框标签
```

也可以输入预先计算好的图像或文本特征。Hugging Face 默认会把图像预处理为最大约 `1008 × 1008`。[接口文档](https://huggingface.co/docs/transformers/model_doc/sam3)

### 输出

对于图像，主要输出为：

```text
pred_masks       每个目标的分割掩码 [B, Q, H, W]
pred_boxes       每个目标的边界框 [B, Q, 4]
pred_logits      每个目标与文本概念的匹配置信度
presence_logits  图中是否存在该概念
semantic_seg     可选的语义分割图
```

其中 `Q` 是模型产生的候选目标数量。经过阈值过滤和尺寸还原后，通常得到：

```text
masks:  [N, H原图, W原图]
boxes:  [N, 4]
scores: [N]
```

对于视频，还会输出：

- 每一帧的目标掩码
- 每个实例的唯一 `object_id`
- 目标置信度
- 跨帧一致的跟踪结果

SAM 3 与早期 SAM 最大的不同是：输入 `"car"` 这样的文本后，它不仅分割一个手动指定的目标，还能找出并分割画面中**所有符合这个开放词汇概念的实例**。[Meta 官方仓库](https://github.com/facebookresearch/sam3)

## 6. 用户

是否是能够识别出 图片里的所有物体有哪些？

## 7. 助手

不完全是。

SAM 3 的核心能力是：

> 给定一个概念提示，找出并分割图片中所有符合该概念的物体。

例如输入：

```text
图片 + “汽车”
```

它会输出图片中所有汽车的：

- 分割掩码
- 边界框
- 置信度

但如果只输入图片，不给任何提示，SAM 3 通常不会直接返回：

```text
汽车、行人、路灯、树、建筑……
```

两种任务的区别是：

| 任务 | SAM 3 是否擅长 |
|---|---|
| 找出所有“汽车” | 是 |
| 分割点击或框选的物体 | 是 |
| 跟踪视频中的指定物体 | 是 |
| 自动罗列图片里所有物体类别 | 不是核心能力 |
| 给每个物体生成详细名称或描述 | 需要视觉语言模型配合 |

如果想实现“识别并分割图片里的所有物体”，通常采用：

```text
图片
  ↓
视觉语言模型或开放词汇检测模型
  ↓ 生成物体类别：人、车、狗、树……
SAM 3
  ↓
为每个类别输出精确掩码
```

因此，更准确地说，SAM 3 是“**按概念找全并分割**”，而不是单独完成“**看图后自动说出所有东西是什么**”。它比 SAM 2 新增的重要能力，正是通过 `"red car"`、`"person wearing a hat"` 等文本概念找出所有匹配实例。[Meta 官方说明](https://github.com/facebookresearch/sam3)
