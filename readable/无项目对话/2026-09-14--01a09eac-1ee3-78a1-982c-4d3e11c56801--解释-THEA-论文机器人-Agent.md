## 3. 助手

你说的应该是 **Thea：《Towards the Harness of Embodied Agents》**，宁波东方理工大学团队的工作。**是机器人 Agent 方向，更准确地说，是让大模型调度机器人能力、完成任务的一套运行框架（harness）。** [论文](https://arxiv.org/abs/2608.11246)

它的思路是把 coding agent 的工作方式搬到物理世界：

- **调用工具做动作**：把机器人的各种能力封装成工具，由大模型决定调用顺序。
- **场景图作为上下文**：维护结构化的环境状态，让模型知道周围有什么、物体之间是什么关系。
- **动作评估作为反馈**：判断动作何时结束、是否成功，以及失败原因，让 agent 能调整策略继续执行。[项目介绍](https://eit-hai.github.io/thea/intro.html)

比如“帮我拿瓶水”，可以理解为：**观察环境 → 找水 → 移动和抓取 → 检查是否拿到 → 失败则调整 → 继续送达**。

所以它的核心贡献在于 **机器人能力的编排、环境记忆和执行反馈闭环**，重点是如何把已有模型和动作能力组织起来，完成较长的真实世界任务。[项目主页](https://eit-hai.github.io/thea/index.html)
