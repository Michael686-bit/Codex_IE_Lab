## 3. 助手

这个 U 盘对应 `/dev/sdb1`，文件系统是 **NTFS**。

- 挂载路径：`/media/lsy03/0BF30C6C0C52E2D0`
- 卷标：`0BF30C6C0C52E2D0`
- `fuseblk` 是挂载驱动显示，实际格式仍是 NTFS。

## 4. 用户

如何格式化？给我命令我来执行

## 5. 助手

你当前终端就在 U 盘目录里，先切到本地目录。以下命令会删除 U 盘上的全部数据：

```bash
cd /tmp
```

先确认设备仍是 `/dev/sdb1`：

```bash
findmnt -T /media/lsy03/0BF30C6C0C52E2D0 -o SOURCE,FSTYPE,TARGET
```

确认输出包含 `/dev/sdb1` 后执行：

```bash
sudo umount /dev/sdb1
sudo mkfs.ntfs -f -L UDISK /dev/sdb1
udisksctl mount -b /dev/sdb1
```

这会将它重新格式化为 **NTFS**。不要把 `/dev/sdb1` 改成 `/dev/sdb`，否则会操作整块磁盘。

## 11. 助手

目前**还没有格式化成功**：

- 第一条命令把 `mkfs.ntfs` 和 `findmnt` 粘成了一行，参数错误。
- 后面的格式化被拒绝，因为 U 盘仍处于挂载状态。

请一行一行执行：

1. 关闭所有打开 U 盘的文件管理器窗口、终端和编辑器，然后执行：

```bash
cd /tmp
sudo fuser -vm /media/lsy03/0BF30C6C0C52E2D0
```

如果显示有进程占用，关闭对应程序。

2. 再卸载：

```bash
sudo umount /media/lsy03/0BF30C6C0C52E2D0
```

3. 卸载成功后，单独执行格式化：

```bash
sudo mkfs.ntfs -f -L UDISK /dev/sdb1
```

4. 重新挂载：

```bash
udisksctl mount -b /dev/sdb1
```

不要执行 `mkfs`，直到 `umount` 成功；否则会继续提示 `Refusing to make a filesystem here!`。
