## 3. 助手

已确认你电脑上的桌面版软件包名是 `chatgpt`，已配置更新源。先保存工作并退出桌面版，然后在终端执行以下代码，会自动检测你启动脚本中使用的手机代理并更新：

```bash
source ~/.bashrc

bash <<'BASH'
set -e

proxy_url=""
for host in 192.168.211.229 192.168.42.129; do
    if timeout 3 bash -c ">/dev/tcp/$host/7890" 2>/dev/null; then
        proxy_url="http://$host:7890"
        break
    fi
done

if [ -z "$proxy_url" ]; then
    echo "未找到手机代理，请检查 USB 网络共享及 Clash 的 Allow LAN。"
    exit 1
fi

echo "使用代理：$proxy_url"
sudo apt-get -o Acquire::http::Proxy="$proxy_url" \
             -o Acquire::https::Proxy="$proxy_url" update

sudo apt-get -o Acquire::http::Proxy="$proxy_url" \
             -o Acquire::https::Proxy="$proxy_url" \
             install --only-upgrade chatgpt

dpkg-query -W chatgpt
BASH
```
