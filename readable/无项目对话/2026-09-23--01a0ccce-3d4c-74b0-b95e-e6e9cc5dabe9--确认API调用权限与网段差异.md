## 4. 助手

**不同网络确实可能有区别。这个 API 在当前电脑上还无法正常访问，因此暂时不能验证密钥能否调用模型。**

我刚才实测了 `https://aigate.catl.com/v1`：

| 检查项 | 结果 |
|---|---|
| 域名解析 | `10.58.16.124`，属于内网地址 |
| 直接访问 HTTPS | 连接超时 |
| 使用当前系统代理访问 | TLS 连接异常中断 |

这说明：**有 API Key 还不够，新电脑必须先能访问公司内网网关。** 但不一定要在同一个网段：

- **公司不同网段**：只要路由互通、防火墙允许，就可能调用。
- **家里或手机热点**：通常需要公司提供的 VPN 或其他内网接入方式。
- **同一网段**：也可能受到设备准入、访问策略和密钥权限限制。

你可以在准备调用的 Windows 电脑上运行：

```powershell
Test-NetConnection aigate.catl.com -Port 443
curl.exe --noproxy "*" -i --connect-timeout 10 https://aigate.catl.com/v1/models
```

判断方法：`TcpTestSucceeded: True` 表示端口可达；HTTP `401` 通常说明已经访问到服务，只是未提供有效认证；超时则优先排查网络、VPN 和防火墙。`/models` 是否受支持还要看网关实现。

另外，附件实际包含了完整密钥，建议更换该密钥，后续只分享脱敏配置。
