## 6. 助手

这块 **18 TB 希捷硬盘已经有 ext4 分区，可以直接挂载使用，无需格式化**。目前未挂载，也没配置开机自动挂载。

可以把它挂载到 `/mnt/data`：

```bash
sudo mkdir -p /mnt/data
sudo mount UUID=892fce27-cf7c-48b9-9dc5-7e69f9d1d78a /mnt/data
```

挂载后，先查看已有文件和剩余容量：

```bash
ls -lah /mnt/data
df -h /mnt/data
```

此后，保存到 `/mnt/data` 下的文件就会占用这块机械硬盘的空间。适合存放数据集、视频、模型文件和备份。

如果普通用户无法写入，可以新建一个属于你的目录：

```bash
sudo mkdir -p /mnt/data/lsy03
sudo chown lsy03:lsy03 /mnt/data/lsy03
```

你就可以直接使用 `/mnt/data/lsy03`。

如果希望**重启后自动挂载**，在 `/etc/fstab` 末尾添加：

```text
UUID=892fce27-cf7c-48b9-9dc5-7e69f9d1d78a /mnt/data ext4 defaults,nofail 0 2
```

以上是操作方法，我还没有执行挂载或修改系统配置。

## 8. 助手

是的，**已经成功挂载到 `/mnt/data`**，目前可用空间约 **16 TiB**。

`already mounted` 只是因为你重复执行了挂载命令，第一次已经成功。`lost+found` 是 ext4 文件系统的正常目录。

目前目录属于 root，再执行下面两条命令，创建你可以直接读写的目录：

```bash
sudo mkdir -p /mnt/data/lsy03
sudo chown lsy03:lsy03 /mnt/data/lsy03
```

之后把文件存到 **`/mnt/data/lsy03`** 即可。当前属于手动挂载，若尚未修改 `/etc/fstab`，重启后需要重新挂载。
