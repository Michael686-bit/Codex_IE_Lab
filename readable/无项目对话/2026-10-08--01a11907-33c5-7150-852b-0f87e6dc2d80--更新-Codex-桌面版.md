## 12. 助手

已确认你安装的是 `chatgpt`，官方更新源也已配置。下面命令会按你的启动脚本探测手机代理，然后更新：

```bash
source ~/.bashrc

(
  proxy=""
  for host in 192.168.211.229 192.168.42.129; do
    if timeout 3 bash -c "</dev/tcp/$host/7890" 2>/dev/null; then
      proxy="http://$host:7890"
      break
    fi
  done

  if [ -z "$proxy" ]; then
    echo "未找到手机代理，请检查 USB 网络共享和 Clash"
    exit 1
  fi

  echo "使用代理：$proxy"
  sudo apt -o Acquire::http::Proxy="$proxy" -o Acquire::https::Proxy="$proxy" update &&
  sudo apt -o Acquire::http::Proxy="$proxy" -o Acquire::https::Proxy="$proxy" install --only-upgrade chatgpt
)
```

更新成功后，执行下面命令重启桌面版（会关闭当前窗口）：

```bash
codex-desktop-proxy
```
